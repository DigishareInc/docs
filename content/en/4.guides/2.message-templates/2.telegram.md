A Telegram template is sent by **your Telegram bot**. There is **no review**: the template is ready as soon as you save it.

::note
**Telegram's rule**: a bot can only write to people who pressed **Start** in the bot. For your existing contacts, see [Link your contacts to Telegram](/en/use-cases/link-contacts-to-telegram).
::

## Steps

::steps

### Choose "Telegram"

Open the editor (the **+** button at the top, then **Message template**) and choose **Telegram**. Or, in an open template, click **Add Telegram**.

### Choose the type

**Text**, **File** or **Buttons** (see below).

### Write the message

Add variables with **Add variable**, or type `{{first_name}}`. The **live preview** on the right shows the message as in Telegram.

### Save

Click **Create template**.

::

## Message types

::tabs
:::tabs-item{label="Text" icon="i-mdi-format-text"}
Up to **4096 characters**. Telegram reads **Markdown** formatting:

| You type | The contact sees |
| :--- | :--- |
| `*text*` | **text** in bold |
| `_text_` | *text* in italics |
| `` `text` `` | `text` as code |
| ` ```text``` ` | a code block |
| `[Our site](https://example.com)` | a link "Our site" |

::::warning
A lone `*` or `_` (not closed) can make the send fail. Always close the formatting.
::::
:::

:::tabs-item{label="File" icon="i-mdi-paperclip"}
An image, a video, a document or an audio, with an optional **caption** (1024 characters, no formatting). Pick the file with **Choose file**, **From library** or **Paste a link** (`https://`).

To send **a different file to each contact**, choose **A different file per contact (variable)**. The variable must hold an `https://` link to the file, not the file itself. See [Base64 files in Telegram campaigns](/en/developer-guides/campaigns/telegram/base64-files).
:::

:::tabs-item{label="Buttons" icon="i-mdi-gesture-tap"}
A text with buttons **under the message**:

- **Reply buttons**: up to 3 buttons, 20 characters each, all different.
- **List**: each row becomes a button under the message.
- **Link button**: a button that opens an `https://` address.

When the contact taps a button, Telegram shows a ✅ and the button's **actions on tap** run, as on WhatsApp.
:::
::

## Good to know

- The **same template** can hold a WhatsApp text and a Telegram text. The variables are shared.
- The **Telegram link** variable gives each contact a personal link to your bot. See [Link your contacts to Telegram](/en/use-cases/link-contacts-to-telegram).
