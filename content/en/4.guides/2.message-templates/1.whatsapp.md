WhatsApp has two kinds of messages. Pick the right one at the start.

| | WhatsApp template | WhatsApp message |
| :--- | :--- | :--- |
| **Review** | Meta must approve it (a few minutes to 24 h) | None |
| **When to send** | Any time, even to a contact who never wrote | Only within **24 h** of the contact's last message |
| **Use** | Campaigns, reminders, notifications | Chat replies, chatbots |

## WhatsApp template (approved by Meta)

::steps

### Choose "WhatsApp template"

Open the editor (the **+** button at the top, then **Message template**) and choose **WhatsApp template**.

### Start from an example (optional)

At the top, the editor offers examples that follow Meta's rules: order confirmation, appointment reminder, verification code… Click **Gallery** to see them all, then **Use template**. Then change the words, the variables and the links.

### Fill in the basics

- **Template title**: what your team sees in Digishare.
- **Meta template name**: lowercase letters, digits and `_` only, for example `order_shipped`.
- **WhatsApp provider**: the WhatsApp number that sends the message.
- **Language**: the language of the text, for example `en` or `fr`.
- **Category**: **Marketing**, **Utility** or **Authentication** (see below).

### Add a header (optional)

Choose **None**, **Text**, **Image**, **Video** or **Document**.

- A **text** header has 60 characters at most, no line break or formatting, and one variable at most.
- A **media** header needs a **sample file**: Meta needs it to review the template. A document must be a **PDF**.

### Write the body

The **body** is required: 1024 characters at most. Formatting: `*bold*`, `_italic_`, `~strike~`, ` ```monospace``` `.

Click **Add variable** to insert `{{1}}`, `{{2}}`… For each variable, give:

- a **key** (for example `first_name`) and a **default value**;
- an **example for Meta's review** (for example `Sara`).

### Add a footer (optional)

One short line, 60 characters at most, **no variables**. For example: *Reply STOP to unsubscribe*.

### Add buttons (optional)

Up to **10 buttons**:

- **Quick reply**: up to 10;
- **Visit website**: up to 2. The URL may end with one variable, for example `https://example.com/track/{{1}}`;
- **Call phone**: 1, with the country code (`+212…`).

A button label has 25 characters at most. Keep quick replies **together**, before or after the other buttons. All the rules: [Button rules](/en/developer-guides/message-templates/whatsapp-button-rules).

### Send to Meta

Click **Save & send to Meta**. The status turns **Pending**, then **Approved** or **Rejected**.

Not ready yet? Click **Save draft**: nothing is sent to Meta.

::

### The carousel

Under **Message**, choose **Carousel** instead of **Standard** to show several products side by side.

- **2 to 10 cards**.
- Each card has a sample **image** or **video**, and a text of 160 characters at most.
- All cards have **the same buttons**. A button you add goes on every card.

### Choose the category

| Category | For | Examples |
| :--- | :--- | :--- |
| **Marketing** | Sell, promote, re-engage | Promotion, new collection, invitation |
| **Utility** | Follow up a customer's action | Order confirmation, delivery, invoice, appointment |
| **Authentication** | Send a code | Verification code (OTP) |

::warning
A **Utility** message that talks about an offer, a discount or a promo will be moved to **Marketing** by Meta. A vague text too. The editor warns you before sending.
::

For **Authentication**, Meta writes the text itself. You only choose:

- whether to add *"For your security, do not share this code."*;
- how long the code is valid (1 to 90 minutes, or empty);
- the label of the **Copy** button.

### Avoid a rejection by Meta

The editor checks Meta's rules while you type. A **"… to fix"** counter shows at the top. The most common causes:

- The body **starts** or **ends** with a variable. Add a few words before or after.
- The variables are **out of order** (`{{1}}`, then `{{3}}`). Click **Fix numbering**.
- The **same variable** is used twice. Meta wants a new number for each place.
- **Too many variables** for a short text, or two variables side by side.
- An **example is missing** for a variable.

If Meta rejects the template, its reason shows with the status (hover over it). Fix the text and send it again.

### Statuses

| Status | What it means |
| :--- | :--- |
| **Draft** | Saved, not sent to Meta. |
| **Pending** | Meta is reviewing it. |
| **Approved** | Ready: you can use it in a campaign. |
| **Rejected** | Meta refused it. Read the reason, fix, send again. |
| **Submit failed** | Meta did not receive the template. Read the error. |
| **Paused** / **Disabled** | Meta stopped it, often after reports from customers. |

## WhatsApp message (24-hour window)

A **WhatsApp message** needs no review. But WhatsApp only delivers it if the contact wrote to you **in the last 24 h**. Use it to reply in the chat or in a chatbot, not for a campaign.

Choose **WhatsApp message**, then the type:

::tabs
:::tabs-item{label="Text" icon="i-mdi-format-text"}
A text of 4096 characters at most, with `*bold*`, `_italic_`, `~strike~` and variables like `{{first_name}}`.
:::

:::tabs-item{label="Media" icon="i-mdi-image-outline"}
An image, a video, a document or an audio, with an optional **caption** (1024 characters). Pick the file with **Choose file**, **From library** or **Paste a link** (`https://`).

| Type | Formats | Max. size |
| :--- | :--- | :--- |
| Image | JPEG, PNG | 5 MB |
| Video | MP4, 3GPP | 16 MB |
| Document | PDF, Word, Excel, PowerPoint, text | 100 MB |
| Audio | AAC, M4A, MP3, AMR, OGG (no caption) | 16 MB |

To send **a different file to each contact** (their invoice, for example), choose **A different file per contact (variable)**. The variable must hold an `https://` link to the file.
:::

:::tabs-item{label="Buttons & lists" icon="i-mdi-gesture-tap-button"}
- **Reply buttons**: up to 3 buttons, 20 characters each, all different.
- **List**: a **menu button** (20 characters) that opens up to 10 rows. Row title: 24 characters, description: 72. With several sections, each section has a title.
- **Link button**: one button (20 characters) that opens an `https://` address.

Header 60 characters, body 1024, footer 60. For each button or row, you can choose **actions on tap**.

Flow, location request, carousel and products: click **More types** (classic editor).
:::
::
