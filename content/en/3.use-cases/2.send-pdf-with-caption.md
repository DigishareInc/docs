A salesperson or a billing system sends a **quote or an invoice as a PDF**, with a short text under it, in **one WhatsApp message**. This page gives a TypeScript script you can run as it is or copy into your own application. It uses the [Event API](/developer-guides/livechat/conversation/send-on-conversation).

::note
**Prerequisites**: an access token (see [Authentication](/developer-guides/authentication)) and the ID of the conversation with the customer, from a [webhook event](/developer-guides/livechat/integration). You need Node 22.18+ or Bun. There is nothing to install. No conversation ID? You can use the customer's number instead: see [Send on Conversation](/developer-guides/livechat/conversation/send-on-conversation#identify-the-conversation).
::

## 1. The script

Save it as `send-pdf.ts`.

```typescript [send-pdf.ts]
// send-pdf.ts: send a PDF with a caption to a Digishare conversation (Event API).
//
// Needs Node 22.18+ or Bun. No packages to install.
//
//   TOKEN=your_token CONVERSATION_ID=your_conversation_id node send-pdf.ts quote.pdf "Your quote, valid until 31 October"
//   TOKEN=your_token CONVERSATION_ID=your_conversation_id bun send-pdf.ts quote.pdf "Your quote, valid until 31 October"
import { readFile } from "node:fs/promises";
import { basename } from "node:path";

const API = process.env.API ?? "https://api-app.digishare.ma";

// The whole event is limited to 1 MB and base64 adds a third: about 700 KB of file.
const MAX_BYTES = 700_000;

interface Accepted {
  event_id: string; // keep it to find the message afterwards
  status: string; // "accepted": the event is queued, the message is created moments later
  timestamp: string;
}

async function sendPdf(token: string, conversationId: string, path: string, caption: string): Promise<Accepted> {
  const pdf = await readFile(path);
  if (pdf.length > MAX_BYTES) {
    throw new Error(`File too large (${pdf.length} bytes): the Event API takes about 700 KB. Send a link instead.`);
  }

  const response = await fetch(`${API}/v1/event/conversation_message`, {
    method: "POST",
    headers: { Authorization: `Bearer ${token}`, "Content-Type": "application/json" },
    body: JSON.stringify({
      conversation_id: conversationId,
      body: "",
      file: { file_name: basename(path), caption, base64: pdf.toString("base64") },
    }),
  });

  if (!response.ok) {
    throw new Error(`HTTP ${response.status}: ${await response.text()}`);
  }
  return (await response.json()) as Accepted;
}

async function main(): Promise<void> {
  const { TOKEN, CONVERSATION_ID } = process.env;
  const [path, caption = ""] = process.argv.slice(2);

  if (!TOKEN || !CONVERSATION_ID || !path) {
    console.error("Usage: TOKEN=... CONVERSATION_ID=... node send-pdf.ts <file.pdf> [caption]");
    process.exit(1);
  }

  const accepted = await sendPdf(TOKEN, CONVERSATION_ID, path, caption);
  console.log(`Queued: event ${accepted.event_id}, status ${accepted.status}`);
}

main().catch((error: unknown) => {
  if (error instanceof Error) {
    const cause = error.cause instanceof Error ? ` (${error.cause.message})` : "";
    console.error(error.message + cause);
  } else {
    console.error(error);
  }
  process.exit(1);
});
```

## 2. Run it

```bash
TOKEN=your_token CONVERSATION_ID=your_conversation_id node send-pdf.ts quote.pdf "Your quote, valid until 31 October"
```

It prints one line when Digishare has queued the message:

```text
Queued: event 2719257001409384448, status accepted
```

A few seconds later the customer receives **one WhatsApp message**: the PDF with the caption under it.

## Good to know

- **Size:** the Event API takes a PDF of up to about **700 KB**. For a larger file, host it and [send a link](/developer-guides/livechat/outgoing-messages/attachments#send-by-link) instead: WhatsApp fetches it itself.
- **`202` means queued, not delivered.** Keep the `event_id` to find the message afterwards: see [Send on Conversation](/developer-guides/livechat/conversation/send-on-conversation#response).
- **A refused file creates no message.** The file is checked after the `202`, so a file of a type that is not allowed, or an invalid base64, gives no error: check it before sending.
- **The caption** belongs to images, videos and documents, and is cut at 1024 characters. See [Text with an attachment](/developer-guides/livechat/outgoing-messages/attachments#text-with-an-attachment).
- **The file name** is what the customer sees, so give the PDF a meaningful name (`quote-2026-001.pdf`).
- **Errors** are printed with the HTTP status, for example `HTTP 403` for an expired token. The script exits with code 1, so it also works in a pipeline.
