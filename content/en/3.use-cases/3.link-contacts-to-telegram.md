title: Link Contacts to Telegram
description: Give each contact a personal link, so your existing contacts can receive your Telegram messages.

---

You want to reach your contacts on Telegram. Telegram has two rules:

- A Telegram account can't be found from a phone number.
- A bot can't write to someone who hasn't pressed **Start**.

So each person taps once. A personal link makes that easy, and Digishare ties their Telegram to their **existing contact**. No duplicate is created.

::note
**Prerequisites**: a Telegram bot connected to your account, an access token (see [Authentication](/developer-guides/authentication)), and contacts with a phone number on Digishare.
::

## 1. How It Works

::steps

### Send the link

Each contact gets their personal link, from a WhatsApp campaign or from your own app.

### The contact taps it

Telegram opens your bot and the contact presses **Start**.

### Digishare links the contact

The bot confirms with "Votre compte est bien lié ✅".

### Your system is told

Your webhook receives `contact_link.linked`. You can now reach this contact on Telegram.

::

## 2. Send the Link by WhatsApp

Digishare fills the **Telegram link** variable for each contact. You don't need it in your contact file.

**With a template button (recommended).** WhatsApp only allows free text within 24 hours of the contact's last message, so most contacts need an approved template.

```text
Body:    Hello {{1}}, get your notifications on Telegram.
Button:  "Activate Telegram" -> https://t.me/your_bot?start={{1}}
```

In the template builder, open the button's `{{1}}` and choose **Telegram link**. Meta must approve the template first.

**With free text.** In the template builder, click **Telegram link** in the Variables section:

```text
Hello {{prenom}}, get your notifications on Telegram:
{{telegram_start_link}}
```

## 3. Get the Links from the API

Send up to 1,000 phone numbers per call, and show each link in your own app or website.

```bash
curl -X POST https://api.digishare.ma/v1/thirds/telegram-start-links \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{ "phones": ["212600000000", "212600000001"] }'
```

```json
{
  "data": [
    {
      "phone": "212600000000",
      "status": "ok",
      "code": "link_x7k2m9p4q1w8z3ab_tb4k2p_9f3a1c7e5d2b8046",
      "link": "https://t.me/your_bot?start=link_x7k2m9p4q1w8z3ab_tb4k2p_9f3a1c7e5d2b8046",
      "expires_at": "2026-11-18T10:30:00+00:00"
    },
    { "phone": "212600000001", "status": "not_found" }
  ]
}
```

`not_found` means this phone number is not a contact on Digishare. If you have more than one bot, add `"provider_id"` to choose one. By default we use your newest bot.

## 4. Get Notified by Webhook

Open your **API** provider, then **Contacts** in the webhook configuration, and add your URL to these events:

| Event | Meaning |
| :--- | :--- |
| `contact_link.linked` | The contact is linked for the first time |
| `contact_link.updated` | The contact moved to another Telegram account |

```json
{
  "event": "contact_link.linked",
  "data": {
    "channel": "telegram",
    "third_id": "x7k2m9p4q1w8z3ab",
    "ext_ref": "USER-1042",
    "phone": "212600000000",
    "platform_id": "123456789",
    "old_platform_id": null,
    "username": "example_user",
    "provider_id": "b5t8r2y6u3i9o1pa",
    "date": "2026-11-04T10:30:00+00:00"
  }
}
```

## 5. What Happens When

Each link is personal and works only on your bot. It contains no phone number. It stays valid for **14 days** and can be used more than once.

| Situation | Result | Webhook |
| :--- | :--- | :--- |
| First tap | The contact is linked | `linked` |
| Same person taps again | "Already linked", nothing changes | None |
| The person pressed Start before, without a link | The chat and its history move to the right contact | `linked` |
| The contact already had another Telegram | The new one replaces it | `updated` |
| This Telegram belongs to another contact | Refused, nothing changes | None |
| The link is expired or wrong | A polite message, nothing changes | None |

If the link doesn't open, the person can send `/link <code>` to the bot.

::warning
Don't ask people to forward their link. If someone else taps it, the contact moves to that person's Telegram.
::

Once your contacts are linked, you can send them files too: see [Sending Base64 Files](/developer-guides/campaigns/telegram/base64-files).
