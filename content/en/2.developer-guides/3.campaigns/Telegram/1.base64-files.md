This guide explains how to send a Telegram campaign with a file encoded as **base64** directly in your API request. You don't need a public file URL or a separate upload.

::note
**Prerequisites**:
- Valid **Bearer Token** in the Authorization header.
- A **Telegram sender** (your bot).
- A **message template** with a Telegram file message whose file is a variable, for example `{{facture}}`.
- The `telegram_id` of each recipient. The person must have pressed **Start** on your bot first.
::

## 1. How It Works

1. In the template builder, add a file message on the Telegram channel and choose **A different file per contact (variable)**. Use a variable such as `{{facture}}`.
2. In your request, pick a placeholder name, for example `PLACEHOLDER_INVOICE`.
3. In `global_data`, give the variable an object that points to this placeholder:
   ```json
   "facture": {
     "provider": "digishare",
     "id": "PLACEHOLDER_INVOICE"
   }
   ```
4. Put the file under the same placeholder name in `base64_files`.
5. Digishare saves the file, replaces the placeholder, and the bot sends the file to each recipient.

::warning
The `id` must be inside this object. A plain string such as `"facture": "PLACEHOLDER_INVOICE"` does not work: the message fails with `failed_file_not_found`.
::

## 2. API Implementation

::api-playground
---
method: POST
url: https://api.digishare.ma/v1/campaigns
description: Create a Telegram campaign with an embedded base64 file.
variables:
  token: YOUR_TOKEN
  senderId: YOUR_SENDER_ID
  templateId: YOUR_TEMPLATE_ID
headers:
  Authorization: Bearer {token}
  Content-Type: application/json
body:
  title: Invoice Distribution Campaign
  channel: telegram
  sender_label_id: "{senderId}"
  message_template_id: "{templateId}"
  global_data:
    telegram_id: "%recipient.telegram_id%"
    facture:
      provider: "digishare"
      id: "PLACEHOLDER_INVOICE"
  recipients:
    - telegram_id: "123456789"
  base64_files:
    PLACEHOLDER_INVOICE:
      base64: "data:application/pdf;base64,JVBERi0xLjQK..."
      file_name: "invoice_12345"
      extension: "pdf"
---
::

## 3. Configuration Fields

The `base64_files` object is a map. Each key is your placeholder, and each value is an object:

| Field | Type | Status | Description |
| :--- | :--- | :--- | :--- |
| `base64` | `string` | **Required** | The file encoded in base64. It can start with the Data URI prefix. |
| `file_name` | `string` | Optional | The name of the file, without the extension. |
| `extension` | `string` | Optional | The file extension (e.g. `pdf`, `png`, `jpg`). |

## 4. Good to Know

- **One file for the campaign.** Every recipient gets the same file. For a different file per contact, send a link per contact in a recipient field and map it in `global_data`: `"facture": "%recipient.facture%"`.
- **The caption** of the file message can use variables, like `Hello {{prenom}}`.
