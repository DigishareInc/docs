Send a static map pin.

::api-playground
---
method: POST
url: "https://api-app.digishare.ma/v1/event/conversation_message"
headers:
  Authorization: "Bearer YOUR_TOKEN"
  Content-Type: "application/json"
body:
  event_type: "conversation_message"
  conversation_id: "CONV_123"
  send_to_third: true
  type: "location"
  body:
    latitude: 33.5731
    longitude: -7.5898
    name: "Digishare HQ"
    address: "Casablanca, Morocco"
responseSample:
  event_id: "2633736349319958528"
  status: "accepted"
  timestamp: "2026-10-02T20:55:33.894921622Z"
---
::

::note
This is the [Event API](/developer-guides/livechat/conversation/send-on-conversation): the request is queued and answered with `202` straight away.
::
