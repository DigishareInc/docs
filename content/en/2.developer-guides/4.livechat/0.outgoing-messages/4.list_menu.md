---
title: List Menu
description: Send an interactive list menu with sections.
icon: i-mdi-send
---


Best for multiple options (up to 10 rows).

::api-playground
---
method: POST
url: "https://api-app.digishare.ma/v1/event/conversation_message"
headers:
  Authorization: "Bearer YOUR_TOKEN"
  Content-Type: "application/json"
body:
  event_type: "conversation_message"
  conversation_id: "CONV_123"
  send_to_third: true
  type: "interactive"
  body:
    type: "list"
    header:
      type: "text"
      text: "Support Menu"
    body:
      text: "Choose a category below:"
    action:
      button: "Select Option"
      sections:
        - title: "Technical Support"
          rows:
            - id: "row_1"
              title: "API Issues"
              description: "Help with integration"
            - id: "row_2"
              title: "Login"
              description: "Account access"
responseSample:
  event_id: "2633736349319958528"
  status: "accepted"
  timestamp: "2026-10-02T20:55:33.894921622Z"
---
::

::note
This is the [Event API](/developer-guides/livechat/conversation/send-on-conversation): the request is queued and answered with `202` straight away. To use `POST /v1/messages` instead, send the same `type` and `body` there; see [LiveChat Integration](/developer-guides/livechat/integration).
::
