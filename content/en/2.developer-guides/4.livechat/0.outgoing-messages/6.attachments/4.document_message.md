---
title: Document Message
description: Send a PDF, spreadsheet or any other file as a downloadable document.
icon: i-mdi-file-document-outline
---

Send any file the customer should download: invoices, contracts, spreadsheets, archives. The WhatsApp API accepts most file types up to **100 MB**. Other provider types have different limits: see [File size limits](/developer-guides/livechat/outgoing-messages/attachments#file-size-limits).

Send it by link or as a file: see [Attachments](/developer-guides/livechat/outgoing-messages/attachments) for how the two differ, every field and the shared rules.

## By link (Event API)

::api-playground
---
method: POST
url: "https://api-app.digishare.ma/v1/event/conversation_message"
headers:
  Authorization: "Bearer YOUR_TOKEN"
  Content-Type: "application/json"
body:
  event_type: "conversation_message"
  conversation_id: "CONV_123"
  send_to_third: true
  type: "document"
  body:
    link: "https://example.com/files/price-list.xlsx"
    filename: "price-list.xlsx"
    caption: "Your text here"
responseSample:
  event_id: "2633736349319958528"
  status: "accepted"
  timestamp: "2026-10-02T20:55:33.894921622Z"
---
::

The link must be public and HTTPS, and `type` must match the file: Digishare does not inspect it. The file is not shown in the Digishare inbox. See [Send by link](/developer-guides/livechat/outgoing-messages/attachments#send-by-link).

## By file (Event API)

Send the document itself, base64-encoded, in `file`. Digishare stores it, shows it in the inbox and detects its type. The event is limited to 1 MB, so the document can be about 700 KB: see [Send a file](/developer-guides/livechat/conversation/send-on-conversation#send-a-file-base64). For a larger one, send it by link.

::api-playground
---
method: POST
url: "https://api-app.digishare.ma/v1/event/conversation_message"
headers:
  Authorization: "Bearer YOUR_TOKEN"
  Content-Type: "application/json"
body:
  event_type: "conversation_message"
  conversation_id: "CONV_123"
  body: ""
  file:
    base64: "JVBERi0xLjQK..."
    file_name: "invoice-2026-001.pdf"
    caption: "Your text here"
responseSample:
  event_id: "2633736349319958528"
  status: "accepted"
  timestamp: "2026-10-02T20:55:33.894921622Z"
---
::

## File name

The customer sees `file_name`, cleaned: only letters, digits, spaces, `_` and `-` are kept, spaces become hyphens, a path is dropped, and the extension always comes from the file's content. You never need `extension`.

| You send                      | The customer sees      |
| :---------------------------- | :--------------------- |
| `invoice-2026-001.pdf`        | `invoice-2026-001.pdf` |
| `Quote 2026.pdf`              | `Quote-2026.pdf`       |
| `../../reports/summary.pdf`   | `summary.pdf`          |
| `report.final.pdf`            | `report_final.pdf`     |

## The `type` you get back

| File                                     | `type`  |
| :--------------------------------------- | :------ |
| PDF                                      | `pdf`   |
| Any other document (DOCX, XLSX, ZIP, ...) | `other` |

Both are delivered on WhatsApp as a document. Use `mime_type` and `extension` in the message `body` when you need to tell file kinds apart.

::note
**Add a caption** with `caption` (`body.caption` by link, `file.caption` by file): the text arrives under the document in the same message. See [Text with an attachment](/developer-guides/livechat/outgoing-messages/attachments#text-with-an-attachment).
::
