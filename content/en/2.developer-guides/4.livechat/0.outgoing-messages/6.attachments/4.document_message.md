Send any file the customer should download: invoices, contracts, spreadsheets, archives. WhatsApp accepts most file types up to **100 MB**. Other provider types have different limits: see [File size limits](/developer-guides/livechat/outgoing-messages/attachments#file-size-limits).

Pass the document in the `file` object. See [Attachments](/developer-guides/livechat/outgoing-messages/attachments) for every field, the base64 option and the shared rules.

::api-playground
---
method: POST
url: "https://api.digishare.ma/v1/messages"
headers:
  Authorization: "Bearer YOUR_TOKEN"
  Content-Type: "application/json"
body:
  send_to_third: true
  conversation_id: "CONV_123"
  file:
    url: "https://example.com/files/price-list.xlsx"
    file_name: "price-list.xlsx"
responseSample:
  data:
    object: "Message"
    id: "MSG_ID"
    conversation_id: "CONV_123"
    type: "other"
    body:
      id: 48217
      name: "price-list"
      file_name: "price-list.xlsx"
      mime_type: "application/vnd.openxmlformats-officedocument.spreadsheetml.sheet"
      extension: "xlsx"
      size: 38912
      type: "other"
      url: "companies/public/message/48217/price-list.xlsx"
      path: "companies/public/message/48217/price-list.xlsx"
    send_to_third: true
    system: false
    status: "sent"
---
::

## File name

For documents, `file_name` is the name the customer sees on the attachment. Always include the extension, and do not also set `extension`:

```json
{ "file_name": "invoice-2026-001.pdf" }
```

```json
{ "file_name": "invoice-2026-001", "extension": "pdf" }
```

Both produce `invoice-2026-001.pdf`. Setting `extension` on a name that already ends with it produces `invoice-2026-001.pdf.pdf`.

## The `type` you get back

| File                                     | `type`  |
| :--------------------------------------- | :------ |
| PDF                                      | `pdf`   |
| Any other document (DOCX, XLSX, ZIP, ...) | `other` |

Both are delivered on WhatsApp as a document. Use `mime_type` and `extension` in the message `body` when you need to tell file kinds apart.
