---
title: Audio Message
description: Send an audio file or a voice note to a conversation.
icon: i-mdi-microphone-outline
---

Send a sound file. The WhatsApp API accepts **AAC**, **AMR**, **MP3**, **M4A** and **OGG (Opus)** up to **16 MB**. Other provider types have different limits: see [File size limits](/developer-guides/livechat/outgoing-messages/attachments#file-size-limits).

Send it by link or by upload: see [Attachments](/developer-guides/livechat/outgoing-messages/attachments) for how the two differ, every field and the shared rules.

## By link (Event API)

::api-playground
---
method: POST
url: "https://api-app.digishare.ma/v1/event/conversation_message"
headers:
  Authorization: "Bearer YOUR_TOKEN"
  Content-Type: "application/json"
body:
  event_type: "conversation_message"
  conversation_id: "CONV_123"
  send_to_third: true
  type: "audio"
  body:
    link: "https://example.com/audio/welcome.mp3"
responseSample:
  event_id: "2633736349319958528"
  status: "accepted"
  timestamp: "2026-10-02T20:55:33.894921622Z"
---
::

The link must be public and HTTPS, and `type` must match the file: Digishare does not inspect it. The file is not shown in the Digishare inbox. See [Send by link](/developer-guides/livechat/outgoing-messages/attachments#send-by-link).

## By upload (Messages API)

### Audio file

::api-playground
---
method: POST
url: "https://api.digishare.ma/v1/messages"
headers:
  Authorization: "Bearer YOUR_TOKEN"
  Content-Type: "application/json"
body:
  send_to_third: true
  conversation_id: "CONV_123"
  file:
    url: "https://example.com/audio/welcome.mp3"
    file_name: "welcome.mp3"
responseSample:
  data:
    object: "Message"
    id: "MSG_ID"
    conversation_id: "CONV_123"
    type: "audio"
    body:
      id: 48216
      name: "welcome"
      file_name: "welcome.mp3"
      mime_type: "audio/mpeg"
      extension: "mp3"
      size: 523488
      type: "audio"
      url: "companies/public/message/48216/welcome.mp3"
      path: "companies/public/message/48216/welcome.mp3"
    send_to_third: true
    system: false
    status: "sent"
---
::

### Voice note (upload, WhatsApp API)

Set `voice: true` to ask for a WhatsApp voice note, with the round play button and waveform, instead of a plain audio attachment. This works on the **WhatsApp API** only.

```json
{
  "send_to_third": true,
  "conversation_id": "CONV_123",
  "file": {
    "url": "https://example.com/audio/reply.ogg",
    "file_name": "reply.ogg",
    "voice": true,
    "duration": 12
  }
}
```

::warning
**Voice notes must be OGG with the Opus codec.** If `voice` is `true` but the file is MP3, M4A, AAC or AMR, it is delivered as a regular audio attachment instead of a voice note. Digishare does not convert the file for you.
::

::note
Files with an extension WhatsApp does not accept as audio (for example `.webm`) are not guaranteed to play. Convert them to OGG (Opus) or MP3 first.
::

::warning
**WhatsApp Business and Messenger numbers (QR-linked) do not send voice notes.** `voice` is ignored there: the file arrives as a regular audio file with a play button, whatever its format. Audio files also take no caption.
::
