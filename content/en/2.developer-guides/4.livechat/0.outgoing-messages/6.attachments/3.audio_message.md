---
title: Audio Message
description: Send an audio file or a voice note to a conversation.
icon: i-mdi-microphone-outline
---

Send a sound file. WhatsApp accepts **AAC**, **AMR**, **MP3**, **M4A** and **OGG (Opus)** up to **16 MB**. Other provider types have different limits: see [File size limits](/developer-guides/livechat/outgoing-messages/attachments#file-size-limits).

Pass the audio in the `file` object. See [Attachments](/developer-guides/livechat/outgoing-messages/attachments) for every field, the base64 option and the shared rules.

## Audio file

::api-playground
---
method: POST
url: "https://api.digishare.ma/v1/messages"
headers:
  Authorization: "Bearer YOUR_TOKEN"
  Content-Type: "application/json"
body:
  send_to_third: true
  conversation_id: "CONV_123"
  file:
    url: "https://example.com/audio/welcome.mp3"
    file_name: "welcome.mp3"
responseSample:
  data:
    object: "Message"
    id: "MSG_ID"
    conversation_id: "CONV_123"
    type: "audio"
    body:
      id: 48216
      name: "welcome"
      file_name: "welcome.mp3"
      mime_type: "audio/mpeg"
      extension: "mp3"
      size: 523488
      type: "audio"
      url: "companies/public/message/48216/welcome.mp3"
      path: "companies/public/message/48216/welcome.mp3"
    send_to_third: true
    system: false
    status: "sent"
---
::

## Voice note

Set `voice: true` to deliver the file as a WhatsApp voice note, with the round play button and waveform, instead of a plain audio attachment.

```json
{
  "send_to_third": true,
  "conversation_id": "CONV_123",
  "file": {
    "url": "https://example.com/audio/reply.ogg",
    "file_name": "reply.ogg",
    "voice": true,
    "duration": 12
  }
}
```

::warning
**Voice notes must be OGG with the Opus codec.** If `voice` is `true` but the file is MP3, M4A, AAC or AMR, it is delivered as a regular audio attachment instead of a voice note. Digishare does not convert the file for you.
::

::note
Files with an extension WhatsApp does not accept as audio (for example `.webm`) are not guaranteed to play. Convert them to OGG (Opus) or MP3 first.
::
