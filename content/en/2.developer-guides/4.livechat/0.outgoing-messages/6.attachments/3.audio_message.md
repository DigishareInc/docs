---
title: Audio Message
description: Send an audio file or a voice note to a conversation.
icon: i-mdi-microphone-outline
---

Send a sound file. The WhatsApp API accepts **AAC**, **AMR**, **MP3**, **M4A** and **OGG (Opus)** up to **16 MB**. Other provider types have different limits: see [File size limits](/developer-guides/livechat/outgoing-messages/attachments#file-size-limits).

Send it by link or as a file: see [Attachments](/developer-guides/livechat/outgoing-messages/attachments) for how the two differ, every field and the shared rules.

## By link (Event API)

::api-playground
---
method: POST
url: "https://api-app.digishare.ma/v1/event/conversation_message"
headers:
  Authorization: "Bearer YOUR_TOKEN"
  Content-Type: "application/json"
body:
  event_type: "conversation_message"
  conversation_id: "CONV_123"
  send_to_third: true
  type: "audio"
  body:
    link: "https://example.com/audio/welcome.mp3"
responseSample:
  event_id: "2633736349319958528"
  status: "accepted"
  timestamp: "2026-10-02T20:55:33.894921622Z"
---
::

The link must be public and HTTPS, and `type` must match the file: Digishare does not inspect it. The file is not shown in the Digishare inbox. See [Send by link](/developer-guides/livechat/outgoing-messages/attachments#send-by-link).

## By file (Event API)

Send the audio file itself, base64-encoded, in `file`. Digishare stores it, shows it in the inbox and detects its type. Accepted formats: OGG, MP3, M4A, AAC and AMR, up to about 700 KB: see [Send a file](/developer-guides/livechat/conversation/send-on-conversation#send-a-file-base64). For a longer recording, send it by link.

::api-playground
---
method: POST
url: "https://api-app.digishare.ma/v1/event/conversation_message"
headers:
  Authorization: "Bearer YOUR_TOKEN"
  Content-Type: "application/json"
body:
  event_type: "conversation_message"
  conversation_id: "CONV_123"
  body: ""
  file:
    base64: "SUQzBAAAAAAAI1RTU0UAAAAPAAADTGF2ZjU4..."
    file_name: "welcome.mp3"
responseSample:
  event_id: "2633736349319958528"
  status: "accepted"
  timestamp: "2026-10-02T20:55:33.894921622Z"
---
::

::note
Audio files take **no caption**: it is ignored and the file is delivered without it.
::
