---
title: Video Message
description: Send an MP4 or 3GPP video to a conversation.
icon: i-mdi-video-outline
---

Send a video clip. WhatsApp accepts **MP4** and **3GPP** files encoded with H.264 video and AAC audio, up to **16 MB**. Other provider types have different limits: see [File size limits](/developer-guides/livechat/outgoing-messages/attachments#file-size-limits).

Pass the video in the `file` object. See [Attachments](/developer-guides/livechat/outgoing-messages/attachments) for every field, the base64 option and the shared rules.

::api-playground
---
method: POST
url: "https://api.digishare.ma/v1/messages"
headers:
  Authorization: "Bearer YOUR_TOKEN"
  Content-Type: "application/json"
body:
  send_to_third: true
  conversation_id: "CONV_123"
  file:
    url: "https://example.com/videos/how-to-pay.mp4"
    file_name: "how-to-pay.mp4"
responseSample:
  data:
    object: "Message"
    id: "MSG_ID"
    conversation_id: "CONV_123"
    type: "video"
    body:
      id: 48215
      name: "how-to-pay"
      file_name: "how-to-pay.mp4"
      mime_type: "video/mp4"
      extension: "mp4"
      size: 4718592
      type: "video"
      url: "companies/public/message/48215/how-to-pay.mp4"
      path: "companies/public/message/48215/how-to-pay.mp4"
    send_to_third: true
    system: false
    status: "sent"
---
::

::warning
**Re-encode before sending.** Digishare accepts other containers (MOV, AVI, MKV, WebM) but WhatsApp may reject them. If a video is not delivered, convert it to MP4 with H.264 video and AAC audio and keep it under 16 MB.
::

::tip
For clips close to the 16 MB limit, host the file and pass `url` rather than `base64`, which is about a third larger on the wire.
::
