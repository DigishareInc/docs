---
title: Video Message
description: Send an MP4 or 3GPP video to a conversation.
icon: i-mdi-video-outline
---

Send a video clip. The WhatsApp API accepts **MP4** and **3GPP** files encoded with H.264 video and AAC audio, up to **16 MB**. Other provider types have different limits: see [File size limits](/developer-guides/livechat/outgoing-messages/attachments#file-size-limits).

Send it by link or by upload: see [Attachments](/developer-guides/livechat/outgoing-messages/attachments) for how the two differ, every field and the shared rules.

## By link (Event API)

::api-playground
---
method: POST
url: "https://api-app.digishare.ma/v1/event/conversation_message"
headers:
  Authorization: "Bearer YOUR_TOKEN"
  Content-Type: "application/json"
body:
  event_type: "conversation_message"
  conversation_id: "CONV_123"
  send_to_third: true
  type: "video"
  body:
    link: "https://example.com/videos/how-to-pay.mp4"
    caption: "Your text here"
responseSample:
  event_id: "2633736349319958528"
  status: "accepted"
  timestamp: "2026-10-02T20:55:33.894921622Z"
---
::

The link must be public and HTTPS, and `type` must match the file: Digishare does not inspect it. The file is not shown in the Digishare inbox. See [Send by link](/developer-guides/livechat/outgoing-messages/attachments#send-by-link).

## By upload (Messages API)

::api-playground
---
method: POST
url: "https://api.digishare.ma/v1/messages"
headers:
  Authorization: "Bearer YOUR_TOKEN"
  Content-Type: "application/json"
body:
  send_to_third: true
  conversation_id: "CONV_123"
  file:
    url: "https://example.com/videos/how-to-pay.mp4"
    file_name: "how-to-pay.mp4"
    caption: "Your text here"
responseSample:
  data:
    object: "Message"
    id: "MSG_ID"
    conversation_id: "CONV_123"
    type: "video"
    body:
      id: 48215
      name: "how-to-pay"
      file_name: "how-to-pay.mp4"
      mime_type: "video/mp4"
      extension: "mp4"
      size: 4718592
      type: "video"
      url: "companies/public/message/48215/how-to-pay.mp4"
      path: "companies/public/message/48215/how-to-pay.mp4"
      caption: "Your text here"
      content: "Your text here"
    send_to_third: true
    system: false
    status: "sent"
---
::

::warning
**Re-encode before sending.** Digishare accepts other containers (MOV, AVI, MKV, WebM) but WhatsApp may reject them. If a video is not delivered, convert it to MP4 with H.264 video and AAC audio and keep it under 16 MB.
::

::tip
For clips close to the 16 MB limit, host the file and pass `url` rather than `base64`, which is about a third larger on the wire.
::

::note
**Add a caption** with `caption` (`body.caption` by link, `file.caption` by upload): the text arrives under the video in the same message. See [Text with an attachment](/developer-guides/livechat/outgoing-messages/attachments#text-with-an-attachment).
::
