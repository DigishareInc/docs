---
title: Image Message
description: Send a JPEG or PNG image to a conversation.
icon: i-mdi-image-outline
---

Send a photo or graphic. The WhatsApp API accepts **JPEG** and **PNG** images (8-bit RGB or RGBA) up to **5 MB**. Other provider types have different limits: see [File size limits](/developer-guides/livechat/outgoing-messages/attachments#file-size-limits).

Send it by link or as a file: see [Attachments](/developer-guides/livechat/outgoing-messages/attachments) for how the two differ, every field and the shared rules.

## By link (Event API)

::api-playground
---
method: POST
url: "https://api-app.digishare.ma/v1/event/conversation_message"
headers:
  Authorization: "Bearer YOUR_TOKEN"
  Content-Type: "application/json"
body:
  event_type: "conversation_message"
  conversation_id: "CONV_123"
  send_to_third: true
  type: "image"
  body:
    link: "https://example.com/images/promo.jpg"
    caption: "Your text here"
responseSample:
  event_id: "2633736349319958528"
  status: "accepted"
  timestamp: "2026-10-02T20:55:33.894921622Z"
---
::

The link must be public and HTTPS, and `type` must match the file: Digishare does not inspect it. The file is not shown in the Digishare inbox. See [Send by link](/developer-guides/livechat/outgoing-messages/attachments#send-by-link).

## By file (Event API)

Send the image itself, base64-encoded, in `file`. Digishare stores it, shows it in the inbox and detects its type. The event is limited to 1 MB, so the image can be about 700 KB: see [Send a file](/developer-guides/livechat/conversation/send-on-conversation#send-a-file-base64).

::api-playground
---
method: POST
url: "https://api-app.digishare.ma/v1/event/conversation_message"
headers:
  Authorization: "Bearer YOUR_TOKEN"
  Content-Type: "application/json"
body:
  event_type: "conversation_message"
  conversation_id: "CONV_123"
  body: ""
  file:
    base64: "/9j/4AAQSkZJRgABAQEASABIAAD..."
    file_name: "promo.jpg"
    caption: "Your text here"
responseSample:
  event_id: "2633736349319958528"
  status: "accepted"
  timestamp: "2026-10-02T20:55:33.894921622Z"
---
::

::warning
**WebP is delivered as a sticker.** A `.webp` file is sent to WhatsApp as a sticker, not as an image, and stickers are limited to 100 KB (static) or 500 KB (animated). The message `type` in the API response is `webp`. Convert to JPEG or PNG for a regular photo.
::

::note
**Add a caption** with `caption` (`body.caption` by link, `file.caption` by file): the text arrives under the image in the same message. See [Text with an attachment](/developer-guides/livechat/outgoing-messages/attachments#text-with-an-attachment).
::
