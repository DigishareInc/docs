---
title: Image Message
description: Send a JPEG or PNG image to a conversation.
icon: i-mdi-image-outline
---

Send a photo or graphic. WhatsApp accepts **JPEG** and **PNG** images (8-bit RGB or RGBA) up to **5 MB**. Other provider types have different limits: see [File size limits](/developer-guides/livechat/outgoing-messages/attachments#file-size-limits).

Send it by link or by upload: see [Attachments](/developer-guides/livechat/outgoing-messages/attachments) for how the two differ, every field and the shared rules.

## By link (Event API)

::api-playground
---
method: POST
url: "https://api-app.digishare.ma/v1/event/conversation_message"
headers:
  Authorization: "Bearer YOUR_TOKEN"
  Content-Type: "application/json"
body:
  event_type: "conversation_message"
  conversation_id: "CONV_123"
  send_to_third: true
  type: "image"
  body:
    link: "https://example.com/images/promo.jpg"
responseSample:
  event_id: "2633736349319958528"
  status: "accepted"
  timestamp: "2026-10-02T20:55:33.894921622Z"
---
::

The link must be public and HTTPS, and `type` must match the file: Digishare does not inspect it. The file is not shown in the Digishare inbox. See [Send by link](/developer-guides/livechat/outgoing-messages/attachments#send-by-link).

## By upload (Messages API)

::api-playground
---
method: POST
url: "https://api.digishare.ma/v1/messages"
headers:
  Authorization: "Bearer YOUR_TOKEN"
  Content-Type: "application/json"
body:
  send_to_third: true
  conversation_id: "CONV_123"
  file:
    url: "https://example.com/images/promo.jpg"
    file_name: "promo.jpg"
responseSample:
  data:
    object: "Message"
    id: "MSG_ID"
    conversation_id: "CONV_123"
    type: "image"
    body:
      id: 48214
      name: "promo"
      file_name: "promo.jpg"
      mime_type: "image/jpeg"
      extension: "jpg"
      size: 184220
      type: "image"
      url: "companies/public/message/48214/promo.jpg"
      path: "companies/public/message/48214/promo.jpg"
    send_to_third: true
    system: false
    status: "sent"
---
::

::warning
**WebP is delivered as a sticker.** A `.webp` file is sent to WhatsApp as a sticker, not as an image, and stickers are limited to 100 KB (static) or 500 KB (animated). The message `type` in the API response is `webp`. Convert to JPEG or PNG for a regular photo.
::

::note
Images are delivered without a caption. To send text with an image, follow it with a [Text Message](/developer-guides/livechat/outgoing-messages/text_message).
::
