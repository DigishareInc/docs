---
title: Media Message
description: Images, videos, audio and documents sent by the customer.

---

When a customer sends a photo, video, voice note or file, your webhook receives a `live_chat.new_message` event. The `type` tells you what kind of file it is, and `body` describes the stored file.

::note
Customer messages are identified by `data.sender.model_type: "third"`. Do not rely on `send_to_third`: it is `false` on text messages but `true` on media messages.
::

## Types

| `type`  | What the customer sent                                  |
| :------ | :------------------------------------------------------ |
| `image` | A photo or image (JPEG, PNG, WebP).                     |
| `webp`  | A WebP image. Treat it like `image`.                    |
| `video` | A video (MP4, WebM).                                    |
| `audio` | A voice note or audio file (OGG, MP3, ...).             |
| `pdf`   | A PDF document.                                         |
| `other` | Any other document (DOCX, XLSX, ZIP, ...).              |

## Payload

All media types share the same `body` shape.

```json
{
  "event": "live_chat.new_message",
  "data": {
    "id": "msg_img123abc456",
    "data": {
      "conversation_id": "conv_abc123xyz789",
      "system": false,
      "type": "image",
      "body": {
        "id": 48213,
        "name": "photo",
        "file_name": "photo.jpg",
        "mime_type": "image/jpeg",
        "extension": "jpg",
        "size": 184220,
        "type": "image",
        "url": "companies/public/message/48213/photo.jpg",
        "path": "companies/public/message/48213/photo.jpg",
        "voice": null,
        "is_voice": null,
        "duration": null
      },
      "send_to_third": true,
      "sent_using": "whatsapp",
      "created_at": "2026-10-02T09:14:31.000000Z",
      "sender": {
        "id": "sndr_thd_pqr456stu012",
        "model_type": "third",
        "model_id": "thd_pqr456stu012",
        "name": "Fatima Zahra"
      }
    }
  }
}
```

### Body fields

| Field         | Type    | Description                                                                                          |
| :------------ | :------ | :--------------------------------------------------------------------------------------------------- |
| `id`          | Number  | Internal ID of the stored file.                                                                      |
| `name`        | String  | Internal name of the stored file. It is not always the file name: use `file_name`.                   |
| `file_name`   | String  | File name, as stored.                                                                                |
| `mime_type`   | String  | MIME type, e.g. `image/jpeg`, `video/mp4`, `audio/ogg`, `application/pdf`.                           |
| `extension`   | String  | File extension without the dot.                                                                      |
| `size`        | Number  | Size in bytes.                                                                                       |
| `type`        | String  | Same as the message `type`.                                                                          |
| `url`, `path` | String  | Storage path of the file. This is **not** a public link: see [Downloading the file](#downloading-the-file). |
| `voice`, `is_voice`, `duration` | Mixed | Audio only, and usually `null` for files sent by customers. |

## Downloading the file

`url` and `path` are identical paths inside Digishare storage, so you cannot open them in a browser. Fetch the file with your access token:

**Endpoint**: `GET https://api.digishare.ma/v1/storages/by/path`

| Query parameter | Required | Description                                                      |
| :-------------- | :------- | :--------------------------------------------------------------- |
| `path`          | **Yes**  | The `body.path` value from the webhook.                          |
| `mime_type`     | No       | Sets the `Content-Type` of the download. Use `body.mime_type`.   |
| `file_name`     | No       | Sets the download file name. Use `body.file_name`.               |

```bash
curl -G "https://api.digishare.ma/v1/storages/by/path" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  --data-urlencode "path=companies/public/message/48213/photo.jpg" \
  --data-urlencode "mime_type=image/jpeg" \
  --data-urlencode "file_name=photo.jpg" \
  -o photo.jpg
```

A missing file returns `404`.

## Other types you may receive

Handle unknown values of `type` gracefully: ignore them rather than failing the webhook.

| `type`        | `body`                                                                 |
| :------------ | :--------------------------------------------------------------------- |
| `sticker`     | `null`. The sticker image is not included in the payload.                             |
| `contacts`    | An array of shared contact cards.                                      |
| `unsupported` | An object with an `errors` array: the channel delivered a message type Digishare cannot display. |
