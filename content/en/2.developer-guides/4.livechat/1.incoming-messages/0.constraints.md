::warning
**Prerequisite**: You must have an active Conversation ID to reply to a user. See [LiveChat Integration](/developer-guides/livechat/integration).
::

When a customer sends a message, your webhook receives a `live_chat.new_message` event. A customer message is the one where `data.sender.model_type` is `"third"`.

::note
Do not use `send_to_third` to tell customer messages from agent messages. It is `false` on text messages sent by a customer but `true` on their media messages.
::

## Message types

The `type` field of the event tells you how to read `body`.

| `type`                               | `body`                                              | Reference                                                                  |
| :----------------------------------- | :-------------------------------------------------- | :------------------------------------------------------------------------- |
| `text`                               | String                                              | [Text Message](/developer-guides/livechat/incoming-messages/text_message)      |
| `location`                           | Object with `latitude` and `longitude`              | [Location Message](/developer-guides/livechat/incoming-messages/location-message) |
| `interactive`                        | Object with the selected button or list row         | [Button / List Response](/developer-guides/livechat/incoming-messages/reply_button) |
| `image`, `webp`, `video`, `audio`, `pdf`, `other` | Object describing the stored file      | [Media Message](/developer-guides/livechat/incoming-messages/media_message)    |
| `sticker`, `contacts`, `unsupported` | `null`, an array, or an object with `errors`        | [Media Message](/developer-guides/livechat/incoming-messages/media_message#other-types-you-may-receive) |

New types can appear over time. Ignore a `type` you do not handle instead of failing the webhook.

## Limits

| Type            | Component        | Limit           |
| :-------------- | :--------------- | :-------------- |
| **Text**        | `body`           | 4096 Characters |
| **Interactive** | `header`         | 60 Characters   |
| **Interactive** | `button` title   | 20 Characters   |
| **Interactive** | `list` row title | 24 Characters   |
| **Image**       | file             | 5 MB            |
| **Video**       | file             | 16 MB           |
| **Audio**       | file             | 16 MB           |
| **Document**    | file             | 100 MB          |

The file limits shown are WhatsApp Business limits. Digishare itself accepts up to 100 MB per file, and other provider types differ: see [File size limits](/developer-guides/livechat/outgoing-messages/attachments#file-size-limits).
