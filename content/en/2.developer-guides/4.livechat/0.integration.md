This guide outlines the technical integration with the Digishare LiveChat system. The integration is bidirectional:

1.  **Webhooks**: Your system listens for real-time events (New Conversations, Incoming Messages).
2.  **API**: Your system sends replies back to the user via the Digishare API.

::note
Ensure you have your **Access Token** ready. See [Authentication](/developer-guides/authentication) for details.
::

## 1. Webhooks

Your system must expose a **POST** endpoint to receive event payloads from Digishare.

### Events

::accordion
::accordion-item{label="New Conversation" icon="i-mdi-plus"}
**Event**: `live_chat.new_conversation`

Triggered when a user initiates a new conversation. Use the `data.id` (Conversation ID) to send replies.

**Payload:**

```json
{
  "event": "live_chat.new_conversation",
  "data": {
    "id": "YOUR_CONVERSATION_ID",
    "data": {
      "created_at": "2025-12-03T12:28:50.000000Z",
      "third": {
        "id": "YOUR_THIRD_ID",
        "name": "Adil Chbada"
      }
    }
  }
}
```

::

::accordion-item{label="Incoming Message" icon="i-mdi-arrow-bottom-left"}
**Event**: `live_chat.new_message`

Triggered when a customer sends a message. `type` tells you how to read `body`: a string for `text`, an object for locations, buttons and media. See [Incoming Messages](/developer-guides/livechat/incoming-messages/constraints).

**Payload:**

```json
{
  "event": "live_chat.new_message",
  "data": {
    "id": "YOUR_MESSAGE_ID",
    "data": {
      "conversation_id": "YOUR_CONVERSATION_ID",
      "type": "text",
      "body": "/info",
      "sender": {
        "model_type": "third",
        "name": "Adil Chbada"
      }
    }
  }
}
```

::
::

## 2. Sending Messages

Digishare gives you two ways to send. For most integrations use the **Event API**: it queues your message and answers in milliseconds, so bursts of messages do not overload your integration or Digishare. For a detailed reference on every message type (text, location, interactive, attachments), see [Outgoing Messages](/developer-guides/livechat/outgoing-messages/text_message), including [Attachments](/developer-guides/livechat/outgoing-messages/attachments) for images, videos, audio and documents.

|                    | **Event API** (recommended)                                              | **Messages API**                                              |
| :----------------- | :----------------------------------------------------------------------- | :------------------------------------------------------------ |
| **Endpoint**       | `POST https://api-app.digishare.ma/v1/event/conversation_message`        | `POST https://api.digishare.ma/v1/messages`                   |
| **Processing**     | Queued. Returns `202` at once; the message is created moments later.     | Synchronous. Returns the created message.                     |
| **Conversation**   | `conversation_id`, or `recipient_id` + `channel` + `api_provider_instance_id` | `conversation_id` (required)                             |
| **Message types**  | Text, location, interactive, attachments **by link**                     | Text, location, interactive, attachments **by upload** (`file`) |
| **Extras**         | `event_id` to find the message later                                     | `reply_to`; the created message in the response               |
| **Limits**         | 1 MB per event                                                           | 100 MB per request                                            |

### Event API

Send a message and get a `202 Accepted` back. See [Send on Conversation](/developer-guides/livechat/conversation/send-on-conversation) for every field.

**Endpoint**: `POST https://api-app.digishare.ma/v1/event/conversation_message`

::api-playground
---
method: POST
url: "https://api-app.digishare.ma/v1/event/conversation_message"
headers:
  Authorization: "Bearer YOUR_TOKEN"
  Content-Type: "application/json"
body:
  event_type: "conversation_message"
  conversation_id: "YOUR_CONVERSATION_ID"
  type: "text"
  send_to_third: true
  body: "Hello! How can I help you?"
responseSample:
  event_id: "2633736349319958528"
  status: "accepted"
  timestamp: "2026-10-02T20:55:33.894921622Z"
---
::

### Messages API

Use it when you need the created message in the response, `reply_to`, or to upload a file.

**Endpoint**: `POST https://api.digishare.ma/v1/messages`

::steps

### Prepare Payload

Construct a JSON body with the message content and target conversation ID.

### Send Request

Send the request with your Bearer Token.

### Verify

Ensure you receive a `200 OK` or `201 Created` response.
::

### Request Body

| Parameter         | Type          | Required | Description                                                                                                       |
| :---------------- | :------------ | :------- | :---------------------------------------------------------------------------------------------------------------- |
| `body`            | String/Object | **Yes**\* | Content of the message: a string for `text`, an object for `location` and `interactive`.                         |
| `file`            | Object        | **Yes**\* | An attachment (image, video, audio or document). See [Attachments](/developer-guides/livechat/outgoing-messages/attachments). |
| `conversation_id` | String        | **Yes**  | ID of the conversation: from the webhook event, or from [Create Conversation](/developer-guides/livechat/conversation/create-conversation).                           |
| `send_to_third`   | Boolean       | **Yes**  | Set `true` to deliver to the user's platform (e.g., WhatsApp).                                                    |
| `type`            | String        | No       | `text` (default), `location` or `interactive`. Not needed with `file`: the type is detected from the file.        |
| `reply_to`        | String        | No       | ID of a message in the same conversation to quote.                                                                |

\* Send `body` **or** `file`. `body` is required unless you send a `file`.

::api-playground
---
method: POST
url: "https://api.digishare.ma/v1/messages"
headers:
  Authorization: "Bearer YOUR_TOKEN"
  Content-Type: "application/json"
body:
  body: "Hello! How can I help you?"
  conversation_id: "YOUR_CONVERSATION_ID"
  send_to_third: true
responseSample:
  id: "msg_123"
  status: "sent"
---
::
