---
title: New Message (Customer)
description: A customer sent a message in a conversation.
---

Fired when a customer sends a message. A customer message is the one where `data.sender.model_type` is `"third"`.

```json
{
  "event": "live_chat.new_message",
  "data": {
    "id": "msg_user123abc456",
    "data": {
      "conversation_id": "conv_abc123xyz789",
      "system": false,
      "type": "text",
      "body": "Thanks for the info!",
      "send_to_third": false,
      "platform_link_id": "plnk_lmn789opq345",
      "platform_link": {
        "id": "plnk_lmn789opq345",
        "platform_id": "212612345678",
        "channel_id": "whatsapp"
      },
      "sent_using": "whatsapp",
      "created_at": "2025-04-30T12:14:02.000000Z",
      "sender": {
        "id": "sndr_thd_pqr456stu012",
        "model_type": "third",
        "model_id": "thd_pqr456stu012",
        "name": "Fatima Zahra"
      }
    }
  }
}
```

The shape of `body` depends on `type`. For photos, videos, voice notes and files, see [Media Message](/developer-guides/livechat/incoming-messages/media_message).
