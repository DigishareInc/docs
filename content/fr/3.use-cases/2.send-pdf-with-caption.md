Un commercial ou un système de facturation envoie un **devis ou une facture en PDF**, avec un court texte en dessous, dans **un seul message WhatsApp**. Cette page fournit un script TypeScript que vous pouvez exécuter tel quel ou copier dans votre application. Il utilise l'[API d'événements](/fr/developer-guides/livechat/conversation/send-message-conversation).

::note
**Prérequis** : un jeton d'accès (voir [Authentification](/fr/developer-guides/authentication)) et l'ID de la conversation avec le client, obtenu depuis un [événement webhook](/fr/developer-guides/livechat/integration). Il faut Node 22.18+ ou Bun. Il n'y a rien à installer. Pas d'ID de conversation ? Vous pouvez utiliser le numéro du client à la place : voir [Envoyer un Message](/fr/developer-guides/livechat/conversation/send-message-conversation#identifier-la-conversation).
::

## 1. Le script

Enregistrez-le sous le nom `send-pdf.ts`.

```typescript [send-pdf.ts]
// send-pdf.ts: send a PDF with a caption to a Digishare conversation (Event API).
//
// Needs Node 22.18+ or Bun. No packages to install.
//
//   TOKEN=your_token CONVERSATION_ID=your_conversation_id node send-pdf.ts quote.pdf "Your quote, valid until 31 October"
//   TOKEN=your_token CONVERSATION_ID=your_conversation_id bun send-pdf.ts quote.pdf "Your quote, valid until 31 October"
import { readFile } from "node:fs/promises";
import { basename } from "node:path";

const API = process.env.API ?? "https://api-app.digishare.ma";

// The whole event is limited to 1 MB and base64 adds a third: about 700 KB of file.
const MAX_BYTES = 700_000;

interface Accepted {
  event_id: string; // keep it to find the message afterwards
  status: string; // "accepted": the event is queued, the message is created moments later
  timestamp: string;
}

async function sendPdf(token: string, conversationId: string, path: string, caption: string): Promise<Accepted> {
  const pdf = await readFile(path);
  if (pdf.length > MAX_BYTES) {
    throw new Error(`File too large (${pdf.length} bytes): the Event API takes about 700 KB. Send a link instead.`);
  }

  const response = await fetch(`${API}/v1/event/conversation_message`, {
    method: "POST",
    headers: { Authorization: `Bearer ${token}`, "Content-Type": "application/json" },
    body: JSON.stringify({
      conversation_id: conversationId,
      body: "",
      file: { file_name: basename(path), caption, base64: pdf.toString("base64") },
    }),
  });

  if (!response.ok) {
    throw new Error(`HTTP ${response.status}: ${await response.text()}`);
  }
  return (await response.json()) as Accepted;
}

async function main(): Promise<void> {
  const { TOKEN, CONVERSATION_ID } = process.env;
  const [path, caption = ""] = process.argv.slice(2);

  if (!TOKEN || !CONVERSATION_ID || !path) {
    console.error("Usage: TOKEN=... CONVERSATION_ID=... node send-pdf.ts <file.pdf> [caption]");
    process.exit(1);
  }

  const accepted = await sendPdf(TOKEN, CONVERSATION_ID, path, caption);
  console.log(`Queued: event ${accepted.event_id}, status ${accepted.status}`);
}

main().catch((error: unknown) => {
  if (error instanceof Error) {
    const cause = error.cause instanceof Error ? ` (${error.cause.message})` : "";
    console.error(error.message + cause);
  } else {
    console.error(error);
  }
  process.exit(1);
});
```

## 2. L'exécuter

```bash
TOKEN=votre_jeton CONVERSATION_ID=votre_id_de_conversation node send-pdf.ts devis.pdf "Votre devis, valable jusqu’au 31 octobre"
```

Il affiche une ligne quand Digishare a mis le message en file d'attente :

```text
Queued: event 2719257001409384448, status accepted
```

Quelques secondes plus tard, le client reçoit **un seul message WhatsApp** : le PDF avec la légende en dessous.

## Bon à savoir

- **Taille :** l'API d'événements accepte un PDF d'environ **700 Ko** au maximum. Pour un fichier plus gros, hébergez-le et [envoyez un lien](/fr/developer-guides/livechat/outgoing-messages/attachments#envoi-par-lien) : WhatsApp le récupère lui-même.
- **`202` signifie mis en file d'attente, pas livré.** Conservez l'`event_id` pour retrouver le message ensuite : voir [Envoyer un Message](/fr/developer-guides/livechat/conversation/send-message-conversation#réponse).
- **Un fichier refusé ne crée aucun message.** Le fichier est vérifié après le `202` : un type non autorisé ou un base64 invalide ne renvoie aucune erreur. Vérifiez-le avant l'envoi.
- **La légende** concerne les images, les vidéos et les documents, et elle est coupée à 1024 caractères. Voir [Texte avec une pièce jointe](/fr/developer-guides/livechat/outgoing-messages/attachments#texte-avec-une-pièce-jointe).
- **Le nom du fichier** est ce que voit le client : donnez au PDF un nom parlant (`devis-2026-001.pdf`).
- **Les erreurs** s'affichent avec le statut HTTP, par exemple `HTTP 403` pour un jeton expiré. Le script se termine avec le code 1, il fonctionne donc aussi dans un pipeline.
