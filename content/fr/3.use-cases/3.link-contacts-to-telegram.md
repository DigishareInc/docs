---
title: Lier vos contacts à Telegram
description: Donnez à chaque contact un lien personnel, pour que vos contacts existants reçoivent vos messages Telegram.
icon: i-mdi-send
---

Vous voulez joindre vos contacts sur Telegram. Telegram a deux règles :

- On ne peut pas trouver un compte Telegram à partir d'un numéro de téléphone.
- Un bot ne peut pas écrire à quelqu'un qui n'a pas appuyé sur **Démarrer** (Start).

Chaque personne doit donc appuyer une fois. Un lien personnel rend cela simple, et Digishare lie son Telegram à son **contact existant**. Aucun doublon n'est créé.

::note
**Prérequis** : un bot Telegram connecté à votre compte, un jeton d'accès (voir [Authentification](/fr/developer-guides/authentication)), et des contacts avec un numéro de téléphone sur Digishare.
::

## 1. Comment ça marche

::steps

### Envoyez le lien

Chaque contact reçoit son lien personnel, par une campagne WhatsApp ou depuis votre application.

### Le contact appuie dessus

Telegram ouvre votre bot et le contact appuie sur **Démarrer**.

### Digishare lie le contact

Le bot confirme avec « Votre compte est bien lié ✅ ».

### Votre système est prévenu

Votre webhook reçoit `contact_link.linked`. Vous pouvez maintenant joindre ce contact sur Telegram.

::

## 2. Envoyer le lien

Choisissez la façon qui vous convient. Les deux donnent à chaque contact le même lien personnel.

### Option A : une campagne WhatsApp

Digishare remplit la variable **Telegram link** pour chaque contact. Vous n'avez pas besoin de l'ajouter à votre fichier de contacts.

**Avec un bouton de template (recommandé).** WhatsApp autorise le texte libre seulement dans les 24 heures après le dernier message du contact, donc la plupart des contacts ont besoin d'un template approuvé.

```text
Corps :   Bonjour {{1}}, recevez vos notifications sur Telegram.
Bouton :  "Activer Telegram" -> https://t.me/your_bot?start={{1}}
```

Dans le créateur de templates, ouvrez le `{{1}}` du bouton et choisissez **Telegram link**. Meta doit d'abord approuver le template.

**Avec du texte libre.** Dans le créateur de templates, cliquez sur **Telegram link** dans la section Variables :

```text
Bonjour {{prenom}}, recevez vos notifications sur Telegram :
{{telegram_start_link}}
```

### Option B : votre application, avec l'API

Envoyez jusqu'à 1 000 numéros par appel, et affichez chaque lien dans votre application ou votre site.

```bash
curl -X POST https://api.digishare.ma/v1/thirds/telegram-start-links \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{ "phones": ["212600000000", "212600000001"] }'
```

```json
{
  "data": [
    {
      "phone": "212600000000",
      "status": "ok",
      "code": "link_x7k2m9p4q1w8z3ab_tb4k2p_9f3a1c7e5d2b8046",
      "link": "https://t.me/your_bot?start=link_x7k2m9p4q1w8z3ab_tb4k2p_9f3a1c7e5d2b8046",
      "expires_at": "2026-11-18T10:30:00+00:00"
    },
    { "phone": "212600000001", "status": "not_found" }
  ]
}
```

`not_found` signifie que ce numéro n'est pas un contact sur Digishare. Si vous avez plusieurs bots, ajoutez `"provider_id"` pour en choisir un. Par défaut, nous utilisons votre bot le plus récent.

## 3. Être prévenu par webhook

Ouvrez votre fournisseur **API**, puis **Contacts** dans la configuration des webhooks, et ajoutez votre URL à ces événements :

| Événement | Signification |
| :--- | :--- |
| `contact_link.linked` | Le contact est lié pour la première fois |
| `contact_link.updated` | Le contact est passé à un autre compte Telegram |

```json
{
  "event": "contact_link.linked",
  "data": {
    "channel": "telegram",
    "third_id": "x7k2m9p4q1w8z3ab",
    "ext_ref": "USER-1042",
    "phone": "212600000000",
    "platform_id": "123456789",
    "old_platform_id": null,
    "username": "example_user",
    "provider_id": "b5t8r2y6u3i9o1pa",
    "date": "2026-11-04T10:30:00+00:00"
  }
}
```

## 4. Que se passe-t-il quand

Chaque lien est personnel et ne marche que sur votre bot. Il ne contient aucun numéro de téléphone. Il reste valable **14 jours** et peut être utilisé plusieurs fois.

| Situation | Résultat | Webhook |
| :--- | :--- | :--- |
| Premier appui | Le contact est lié | `linked` |
| La même personne appuie encore | « Déjà lié », rien ne change | Aucun |
| La personne avait appuyé sur Démarrer avant, sans lien | La discussion et son historique passent au bon contact | `linked` |
| Le contact avait déjà un autre Telegram | Le nouveau le remplace | `updated` |
| Ce Telegram appartient à un autre contact | Refusé, rien ne change | Aucun |
| Le lien est expiré ou incorrect | Un message poli, rien ne change | Aucun |

Si le lien ne s'ouvre pas, la personne peut envoyer `/link <code>` au bot.

::warning
Ne demandez pas aux gens de transférer leur lien. Si quelqu'un d'autre appuie dessus, le contact passe sur le Telegram de cette personne.
::

Une fois vos contacts liés, vous pouvez aussi leur envoyer des fichiers : voir [Envoyer des fichiers en Base64](/fr/developer-guides/campaigns/telegram/base64-files).
