WhatsApp a deux sortes de messages. Choisissez la bonne au début.

| | Modèle WhatsApp | Message WhatsApp |
| :--- | :--- | :--- |
| **Validation** | Meta doit l'approuver (de quelques minutes à 24 h) | Aucune |
| **Quand l'envoyer** | À tout moment, même à un contact qui n'a jamais écrit | Seulement dans les **24 h** après le dernier message du contact |
| **Usage** | Campagnes, rappels, notifications | Réponses dans le chat, chatbots |

## Modèle WhatsApp (approuvé par Meta)

::steps

### Choisissez « Modèle WhatsApp »

Ouvrez l'éditeur (bouton **+** en haut, puis **Modèle de message**) et choisissez **Modèle WhatsApp**.

### Partez d'un exemple (facultatif)

En haut, l'éditeur propose des exemples qui respectent les règles de Meta : confirmation de commande, rappel de rendez-vous, code de vérification… Cliquez sur **Galerie** pour tous les voir, puis sur **Utiliser le modèle**. Changez ensuite les mots, les variables et les liens.

### Remplissez l'essentiel

- **Titre du modèle** : ce que votre équipe voit dans Digishare.
- **Nom du modèle chez Meta** : minuscules, chiffres et `_` seulement, par exemple `commande_expediee`.
- **Fournisseur WhatsApp** : le numéro WhatsApp qui enverra le message.
- **Langue** : la langue du texte, par exemple `fr` ou `ar`.
- **Catégorie** : **Marketing**, **Utilitaire** ou **Authentification** (voir plus bas).

### Ajoutez un en-tête (facultatif)

Choisissez **Aucun**, **Texte**, **Image**, **Vidéo** ou **Document**.

- Un en-tête **texte** fait 60 caractères au maximum, sans retour à la ligne ni mise en forme, avec une variable au plus.
- Un en-tête **média** demande un **fichier d'exemple** : Meta en a besoin pour valider le modèle. Un document doit être un **PDF**.

### Écrivez le corps

Le **corps** est obligatoire : 1024 caractères au maximum. Mise en forme : `*gras*`, `_italique_`, `~barré~`, ` ```chasse fixe``` `.

Cliquez sur **Ajouter une variable** pour insérer `{{1}}`, `{{2}}`… Pour chaque variable, donnez :

- une **clé** (par exemple `prenom`) et une **valeur par défaut** ;
- un **exemple pour la validation Meta** (par exemple `Sara`).

### Ajoutez un pied de page (facultatif)

Une ligne courte, 60 caractères au maximum, **sans variable**. Par exemple : *Répondez STOP pour vous désabonner*.

### Ajoutez des boutons (facultatif)

Jusqu'à **10 boutons** :

- **Réponse rapide** : jusqu'à 10 ;
- **Visiter le site** : jusqu'à 2. L'URL peut finir par une seule variable, par exemple `https://exemple.ma/suivi/{{1}}` ;
- **Appeler** : 1, avec l'indicatif du pays (`+212…`).

Le libellé d'un bouton fait 25 caractères au maximum. Gardez les réponses rapides **ensemble**, avant ou après les autres boutons. Toutes les règles : [Règles des boutons](/fr/developer-guides/message-templates/whatsapp-button-rules).

### Envoyez à Meta

Cliquez sur **Enregistrer et envoyer à Meta**. Le statut passe à **En attente**, puis à **Approuvé** ou **Refusé**.

Pas encore prêt ? Cliquez sur **Enregistrer le brouillon** : rien n'est envoyé à Meta.

::

### Le carrousel

Dans **Message**, choisissez **Carrousel** au lieu de **Standard** pour montrer plusieurs produits côte à côte.

- De **2 à 10 cartes**.
- Chaque carte a une **image** ou une **vidéo** d'exemple, et un texte de 160 caractères au maximum.
- Les cartes ont **les mêmes boutons**. Un bouton ajouté s'ajoute à toutes les cartes.

### Choisir la catégorie

| Catégorie | Pour | Exemples |
| :--- | :--- | :--- |
| **Marketing** | Vendre, promouvoir, relancer | Promotion, nouvelle collection, invitation |
| **Utilitaire** | Suivre une action du client | Confirmation de commande, livraison, facture, rendez-vous |
| **Authentification** | Envoyer un code | Code de vérification (OTP) |

::warning
Un message **Utilitaire** qui parle d'offre, de réduction ou de promo sera classé **Marketing** par Meta. Un texte trop vague aussi. L'éditeur vous prévient avant l'envoi.
::

Pour **Authentification**, Meta écrit le texte elle-même. Vous choisissez seulement :

- d'ajouter ou non la phrase *« Pour votre sécurité, ne partagez pas ce code. »* ;
- la durée de validité du code (1 à 90 minutes, ou vide) ;
- le libellé du bouton **Copier**.

### Éviter un refus de Meta

L'éditeur vérifie les règles de Meta pendant que vous écrivez. Un compteur **« … à corriger »** apparaît en haut. Les causes les plus fréquentes :

- Le corps **commence** ou **finit** par une variable. Ajoutez quelques mots avant ou après.
- Les variables ne sont **pas dans l'ordre** (`{{1}}`, puis `{{3}}`). Cliquez sur **Corriger la numérotation**.
- La **même variable** est utilisée deux fois. Meta veut un nouveau numéro par emplacement.
- **Trop de variables** pour un texte court, ou deux variables collées.
- Un **exemple manque** pour une variable.

Si Meta refuse le modèle, sa raison s'affiche avec le statut (passez la souris dessus). Corrigez le texte et envoyez-le de nouveau.

### Les statuts

| Statut | Ce que ça veut dire |
| :--- | :--- |
| **Brouillon** | Enregistré, pas envoyé à Meta. |
| **En attente** | Meta est en train de le vérifier. |
| **Approuvé** | Prêt : vous pouvez l'utiliser dans une campagne. |
| **Refusé** | Meta l'a refusé. Lisez la raison, corrigez, renvoyez. |
| **Échec de l'envoi** | Meta n'a pas reçu le modèle. Lisez l'erreur. |
| **En pause** / **Désactivé** | Meta l'a arrêté, souvent après des signalements de clients. |

## Message WhatsApp (fenêtre de 24 h)

Un **Message WhatsApp** n'a pas besoin de validation. Mais WhatsApp le livre seulement si le contact vous a écrit **dans les dernières 24 h**. Utilisez-le pour répondre dans le chat ou dans un chatbot, pas pour une campagne.

Choisissez **Message WhatsApp**, puis le type :

::tabs
:::tabs-item{label="Texte" icon="i-mdi-format-text"}
Un texte de 4096 caractères au maximum, avec `*gras*`, `_italique_`, `~barré~` et des variables comme `{{prenom}}`.
:::

:::tabs-item{label="Média" icon="i-mdi-image-outline"}
Une image, une vidéo, un document ou un audio, avec une **légende** facultative (1024 caractères). Choisissez le fichier avec **Choisir un fichier**, **Depuis la bibliothèque** ou **Coller un lien** (`https://`).

| Type | Formats | Taille max. |
| :--- | :--- | :--- |
| Image | JPEG, PNG | 5 Mo |
| Vidéo | MP4, 3GPP | 16 Mo |
| Document | PDF, Word, Excel, PowerPoint, texte | 100 Mo |
| Audio | AAC, M4A, MP3, AMR, OGG (sans légende) | 16 Mo |

Pour envoyer **un fichier différent à chaque contact** (par exemple sa facture), choisissez **Un fichier différent par contact (variable)**. La variable doit contenir un lien `https://` vers le fichier.
:::

:::tabs-item{label="Boutons et listes" icon="i-mdi-gesture-tap-button"}
- **Boutons de réponse** : jusqu'à 3 boutons, 20 caractères chacun, tous différents.
- **Liste** : un **bouton du menu** (20 caractères) qui ouvre jusqu'à 10 lignes. Titre d'une ligne : 24 caractères, description : 72. Avec plusieurs sections, chaque section a un titre.
- **Bouton lien** : un bouton (20 caractères) qui ouvre une adresse `https://`.

En-tête 60 caractères, corps 1024, pied de page 60. Pour chaque bouton ou ligne, vous pouvez choisir des **actions au clic**.

Flow, demande de position, carrousel et produits : cliquez sur **Plus de types** (éditeur classique).
:::
::
