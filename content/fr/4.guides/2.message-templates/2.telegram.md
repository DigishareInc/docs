Un modèle Telegram est envoyé par **votre bot Telegram**. Il n'y a **pas de validation** : le modèle est prêt dès qu'il est enregistré.

::note
**Règle de Telegram** : un bot peut écrire seulement aux personnes qui ont appuyé sur **Démarrer** (Start) dans le bot. Pour vos contacts existants, voir [Lier vos contacts à Telegram](/fr/use-cases/link-contacts-to-telegram).
::

## Étapes

::steps

### Choisissez « Telegram »

Ouvrez l'éditeur (bouton **+** en haut, puis **Modèle de message**) et choisissez **Telegram**. Ou, dans un modèle déjà ouvert, cliquez sur **Ajouter Telegram**.

### Choisissez le type

**Texte**, **Fichier** ou **Boutons** (voir plus bas).

### Écrivez le message

Ajoutez des variables avec **Ajouter une variable**, ou écrivez `{{prenom}}`. L'**aperçu en direct** à droite montre le message comme dans Telegram.

### Enregistrez

Cliquez sur **Créer le modèle**.

::

## Les types de message

::tabs
:::tabs-item{label="Texte" icon="i-mdi-format-text"}
Jusqu'à **4096 caractères**. Telegram lit la mise en forme **Markdown** :

| Vous écrivez | Le contact voit |
| :--- | :--- |
| `*texte*` | **texte** en gras |
| `_texte_` | *texte* en italique |
| `` `texte` `` | `texte` en code |
| ` ```texte``` ` | un bloc de code |
| `[Notre site](https://exemple.ma)` | un lien « Notre site » |

::::warning
Un `*` ou un `_` seul (non fermé) peut faire échouer l'envoi. Fermez toujours la mise en forme.
::::
:::

:::tabs-item{label="Fichier" icon="i-mdi-paperclip"}
Une image, une vidéo, un document ou un audio, avec une **légende** facultative (1024 caractères, sans mise en forme). Choisissez le fichier avec **Choisir un fichier**, **Depuis la bibliothèque** ou **Coller un lien** (`https://`).

Pour envoyer **un fichier différent à chaque contact**, choisissez **Un fichier différent par contact (variable)**. La variable doit contenir un lien `https://` vers le fichier, pas le fichier lui-même. Voir [Fichiers en base64 dans les campagnes Telegram](/fr/developer-guides/campaigns/telegram/base64-files).
:::

:::tabs-item{label="Boutons" icon="i-mdi-gesture-tap"}
Un texte avec des boutons **sous le message** :

- **Boutons de réponse** : jusqu'à 3 boutons, 20 caractères chacun, tous différents.
- **Liste** : chaque ligne devient un bouton sous le message.
- **Bouton lien** : un bouton qui ouvre une adresse `https://`.

Quand le contact appuie sur un bouton, Telegram affiche un ✅ et les **actions au clic** du bouton se lancent, comme sur WhatsApp.
:::
::

## Bon à savoir

- Le **même modèle** peut avoir un texte WhatsApp et un texte Telegram. Les variables sont partagées.
- La variable **Lien Telegram** donne à chaque contact son lien personnel vers votre bot. Voir [Lier vos contacts à Telegram](/fr/use-cases/link-contacts-to-telegram).
