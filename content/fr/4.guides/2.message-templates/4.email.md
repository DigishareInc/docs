Un modèle e-mail contient le **corps** de l'e-mail. Il n'y a **pas de validation**. L'**objet** de l'e-mail se règle dans la campagne.

## Étapes

::steps

### Choisissez « Email »

Ouvrez l'éditeur (bouton **+** en haut, puis **Modèle de message**) et choisissez **Email**. Ou, dans un modèle déjà ouvert, cliquez sur **Ajouter Email**.

### Choisissez l'éditeur

- **Glisser-déposer** : un éditeur visuel. Glissez des blocs (texte, image, bouton, colonnes) depuis la gauche.
- **HTML** : collez ou écrivez votre propre code HTML.

### Ajoutez des variables

Écrivez `{{prenom}}` dans le texte.

Dans l'éditeur **Glisser-déposer**, cliquez d'abord sur **Obtenir des variables**, puis tapez `@` dans un texte pour choisir une variable du modèle.

### Enregistrez

Cliquez sur **Créer le modèle**.

::

::warning
Dans l'éditeur **Glisser-déposer**, votre travail est gardé quand **la souris sort de l'éditeur**. Avant d'enregistrer, sortez la souris de la zone d'édition.
::

## Bon à savoir

- Changer d'éditeur (**Glisser-déposer** ↔ **HTML**) **efface** le contenu actuel de l'e-mail. L'éditeur vous demande de confirmer.
- Le **même modèle** peut avoir un e-mail et un texte WhatsApp, Telegram ou SMS. Les variables sont partagées.
