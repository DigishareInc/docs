  "event": "live_chat.new_message",
  "data": {
    "id": "msg_agent789def012",
    "data": {
      "conversation_id": "conv_abc123xyz789",
      "system": false,
      "type": "text",
      "body": "Hi Fatima, I can help you with that. What is your order number?",
      "send_to_third": true,

      "created_at": "2025-04-30T12:15:05.000000Z",

        "id": "sndr_usr_agent_support_01",

Lorsque l'agent envoie un fichier, `type` vaut `image`, `video`, `audio`, `pdf` ou `other` et `body` décrit le fichier enregistré. Voir [Pièces jointes](/fr/developer-guides/livechat/outgoing-messages/attachments).
