title: Message Client

---

Déclenché lorsqu'un client envoie un message. Un message client est celui où `data.sender.model_type` vaut `"third"`.

```json
{
  "event": "live_chat.new_message",
  "data": {
    "id": "msg_user123abc456",
    "data": {
      "conversation_id": "conv_abc123xyz789",
      "system": false,
      "type": "text",
      "body": "Thanks for the info!",
      "send_to_third": false,
      "platform_link_id": "plnk_lmn789opq345",
      "platform_link": {
        "id": "plnk_lmn789opq345",
        "platform_id": "212612345678",
        "channel_id": "whatsapp"
      },
      "sent_using": "whatsapp",
      "created_at": "2025-04-30T12:14:02.000000Z",
      "sender": {
        "id": "sndr_thd_pqr456stu012",
        "model_type": "third",
        "model_id": "thd_pqr456stu012",
        "name": "Fatima Zahra"
      }
    }
  }
}
```

La structure de `body` dépend de `type`. Pour les photos, vidéos, messages vocaux et fichiers, voir [Message Média](/fr/developer-guides/livechat/incoming-messages/media_message).
