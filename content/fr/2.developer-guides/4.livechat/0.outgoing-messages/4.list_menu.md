---
title: Menu Liste
description: Envoyez un menu liste interactif avec des sections.
icon: i-mdi-send
---

Idéal pour les options multiples (jusqu'à 10 lignes).

::api-playground
---
method: POST
url: "https://api-app.digishare.ma/v1/event/conversation_message"
headers:
  Authorization: "Bearer VOTRE_TOKEN"
  Content-Type: "application/json"
body:
  event_type: "conversation_message"
  conversation_id: "CONV_123"
  send_to_third: true
  type: "interactive"
  body:
    type: "list"
    header:
      type: "text"
      text: "Menu Support"
    body:
      text: "Choisissez une catégorie ci-dessous :"
    action:
      button: "Sélectionner une Option"
      sections:
        - title: "Support Technique"
          rows:
            - id: "row_1"
              title: "Problèmes API"
              description: "Aide à l'intégration"
            - id: "row_2"
              title: "Connexion"
              description: "Accès au compte"
responseSample:
  event_id: "2633736349319958528"
  status: "accepted"
  timestamp: "2026-10-02T20:55:33.894921622Z"
---
::

::note
Il s'agit de l'[API d'événements](/fr/developer-guides/livechat/conversation/send-message-conversation) : la requête est mise en file d'attente et reçoit immédiatement un `202`. Pour utiliser `POST /v1/messages` à la place, envoyez-y les mêmes `type` et `body` ; voir [Intégration LiveChat](/fr/developer-guides/livechat/integration).
::
