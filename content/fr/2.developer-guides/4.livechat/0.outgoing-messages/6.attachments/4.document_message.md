Envoyez n'importe quel fichier que le client doit télécharger : factures, contrats, tableurs, archives. L'API WhatsApp accepte la plupart des types de fichiers jusqu'à **100 Mo**. Les autres types de fournisseur ont des limites différentes : voir [Limites de taille des fichiers](/fr/developer-guides/livechat/outgoing-messages/attachments#limites-de-taille-des-fichiers).

Envoyez-le par lien ou par upload : voir [Pièces jointes](/fr/developer-guides/livechat/outgoing-messages/attachments) pour les différences entre les deux, tous les champs et les règles communes.

## Par lien (API d'événements)

::api-playground
---
method: POST
url: "https://api-app.digishare.ma/v1/event/conversation_message"
headers:
  Authorization: "Bearer VOTRE_TOKEN"
  Content-Type: "application/json"
body:
  event_type: "conversation_message"
  conversation_id: "CONV_123"
  send_to_third: true
  type: "document"
  body:
    link: "https://example.com/files/liste-prix.xlsx"
    filename: "liste-prix.xlsx"
    caption: "Votre texte ici"
responseSample:
  event_id: "2633736349319958528"
  status: "accepted"
  timestamp: "2026-10-02T20:55:33.894921622Z"
---
::

Le lien doit être public et en HTTPS, et `type` doit correspondre au fichier : Digishare ne l'inspecte pas. Le fichier n'est pas visible dans l'inbox Digishare. Voir [Envoi par lien](/fr/developer-guides/livechat/outgoing-messages/attachments#envoi-par-lien).

## Par upload (API Messages)

::api-playground
---
method: POST
url: "https://api.digishare.ma/v1/messages"
headers:
  Authorization: "Bearer VOTRE_TOKEN"
  Content-Type: "application/json"
body:
  send_to_third: true
  conversation_id: "CONV_123"
  file:
    url: "https://example.com/files/liste-prix.xlsx"
    file_name: "liste-prix.xlsx"
    caption: "Votre texte ici"
responseSample:
  data:
    object: "Message"
    id: "MSG_ID"
    conversation_id: "CONV_123"
    type: "other"
    body:
      id: 48217
      name: "liste-prix"
      file_name: "liste-prix.xlsx"
      mime_type: "application/vnd.openxmlformats-officedocument.spreadsheetml.sheet"
      extension: "xlsx"
      size: 38912
      type: "other"
      url: "companies/public/message/48217/liste-prix.xlsx"
      path: "companies/public/message/48217/liste-prix.xlsx"
      caption: "Votre texte ici"
      content: "Votre texte ici"
    send_to_third: true
    system: false
    status: "sent"
---
::

## Nom du fichier

Pour les documents, `file_name` est le nom que voit le client sur la pièce jointe. Incluez toujours l'extension, et ne renseignez pas aussi `extension` :

```json
{ "file_name": "facture-2026-001.pdf" }
```

```json
{ "file_name": "facture-2026-001", "extension": "pdf" }
```

Les deux produisent `facture-2026-001.pdf`. Renseigner `extension` sur un nom qui se termine déjà par celle-ci produit `facture-2026-001.pdf.pdf`.

## Le `type` renvoyé

| Fichier                                      | `type`  |
| :------------------------------------------- | :------ |
| PDF                                          | `pdf`   |
| Tout autre document (DOCX, XLSX, ZIP, ...)   | `other` |

Les deux sont livrés sur WhatsApp comme document. Utilisez `mime_type` et `extension` dans le `body` du message pour distinguer les types de fichiers.

::note
**Ajoutez une légende** avec `caption` (`body.caption` par lien, `file.caption` par upload) : le texte arrive sous le document dans le même message. Voir [Texte avec une pièce jointe](/fr/developer-guides/livechat/outgoing-messages/attachments#texte-avec-une-pièce-jointe).
::
