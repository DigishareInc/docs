title: Message Document
description: Envoyez un PDF, un tableur ou tout autre fichier comme document téléchargeable.

---

Envoyez n'importe quel fichier que le client doit télécharger : factures, contrats, tableurs, archives. L'API WhatsApp accepte la plupart des types de fichiers jusqu'à **100 Mo**. Les autres types de fournisseur ont des limites différentes : voir [Limites de taille des fichiers](/fr/developer-guides/livechat/outgoing-messages/attachments#limites-de-taille-des-fichiers).

Envoyez-le par lien ou comme fichier : voir [Pièces jointes](/fr/developer-guides/livechat/outgoing-messages/attachments) pour les différences entre les deux, tous les champs et les règles communes.

## Par lien (API d'événements)

::api-playground
---
method: POST
url: "https://api-app.digishare.ma/v1/event/conversation_message"
headers:
  Authorization: "Bearer VOTRE_TOKEN"
  Content-Type: "application/json"
body:
  event_type: "conversation_message"
  conversation_id: "CONV_123"
  send_to_third: true
  type: "document"
  body:
    link: "https://example.com/files/liste-prix.xlsx"
    filename: "liste-prix.xlsx"
    caption: "Votre texte ici"
responseSample:
  event_id: "2633736349319958528"
  status: "accepted"
  timestamp: "2026-10-02T20:55:33.894921622Z"
---
::

Le lien doit être public et en HTTPS, et `type` doit correspondre au fichier : Digishare ne l'inspecte pas. Le fichier n'est pas visible dans l'inbox Digishare. Voir [Envoi par lien](/fr/developer-guides/livechat/outgoing-messages/attachments#envoi-par-lien).

## Par fichier (API d'événements)

Envoyez le document lui-même, encodé en base64, dans `file`. Digishare le conserve, l'affiche dans l'inbox et détecte son type. L'événement est limité à 1 Mo, le document peut donc faire environ 700 Ko : voir [Envoyer un fichier](/fr/developer-guides/livechat/conversation/send-message-conversation#envoyer-un-fichier-base64). Pour un document plus gros, envoyez-le par lien.

::api-playground
---
method: POST
url: "https://api-app.digishare.ma/v1/event/conversation_message"
headers:
  Authorization: "Bearer YOUR_TOKEN"
  Content-Type: "application/json"
body:
  event_type: "conversation_message"
  conversation_id: "CONV_123"
  body: ""
  file:
    base64: "JVBERi0xLjQK..."
    file_name: "facture-2026-001.pdf"
    caption: "Votre texte ici"
responseSample:
  event_id: "2633736349319958528"
  status: "accepted"
  timestamp: "2026-10-02T20:55:33.894921622Z"
---
::

## Nom du fichier

Le client voit `file_name`, nettoyé : seuls les lettres, chiffres, espaces, `_` et `-` sont conservés, les espaces deviennent des tirets, un chemin est supprimé, et l'extension vient toujours du contenu du fichier. Vous n'avez jamais besoin de `extension`.

| Vous envoyez                  | Le client voit         |
| :---------------------------- | :--------------------- |
| `facture-2026-001.pdf`        | `facture-2026-001.pdf` |
| `Devis 2026.pdf`              | `Devis-2026.pdf`       |
| `../../rapports/synthese.pdf` | `synthese.pdf`         |
| `rapport.final.pdf`           | `rapport_final.pdf`    |

## Le `type` renvoyé

| Fichier                                      | `type`  |
| :------------------------------------------- | :------ |
| PDF                                          | `pdf`   |
| Tout autre document (DOCX, XLSX, ZIP, ...)   | `other` |

Les deux sont livrés sur WhatsApp comme document. Utilisez `mime_type` et `extension` dans le `body` du message pour distinguer les types de fichiers.

::note
**Ajoutez une légende** avec `caption` (`body.caption` par lien, `file.caption` par fichier) : le texte arrive sous le document dans le même message. Voir [Texte avec une pièce jointe](/fr/developer-guides/livechat/outgoing-messages/attachments#texte-avec-une-pièce-jointe).
::
