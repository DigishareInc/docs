---
title: Message Image
description: Envoyez une image JPEG ou PNG dans une conversation.
icon: i-mdi-image-outline
---

Envoyez une photo ou un visuel. WhatsApp accepte les images **JPEG** et **PNG** (8 bits RVB ou RVBA) jusqu'à **5 Mo**. Les autres types de fournisseur ont des limites différentes : voir [Limites de taille des fichiers](/fr/developer-guides/livechat/outgoing-messages/attachments#limites-de-taille-des-fichiers).

Passez l'image dans l'objet `file`. Voir [Pièces jointes](/fr/developer-guides/livechat/outgoing-messages/attachments) pour tous les champs, l'option base64 et les règles communes.

::api-playground
---
method: POST
url: "https://api.digishare.ma/v1/messages"
headers:
  Authorization: "Bearer VOTRE_TOKEN"
  Content-Type: "application/json"
body:
  send_to_third: true
  conversation_id: "CONV_123"
  file:
    url: "https://example.com/images/promo.jpg"
    file_name: "promo.jpg"
responseSample:
  data:
    object: "Message"
    id: "MSG_ID"
    conversation_id: "CONV_123"
    type: "image"
    body:
      id: 48214
      name: "promo"
      file_name: "promo.jpg"
      mime_type: "image/jpeg"
      extension: "jpg"
      size: 184220
      type: "image"
      url: "companies/public/message/48214/promo.jpg"
      path: "companies/public/message/48214/promo.jpg"
    send_to_third: true
    system: false
    status: "sent"
---
::

::warning
**Le WebP est livré comme sticker.** Un fichier `.webp` est envoyé à WhatsApp comme sticker, pas comme image, et les stickers sont limités à 100 Ko (statique) ou 500 Ko (animé). Le `type` du message dans la réponse de l'API est `webp`. Convertissez en JPEG ou PNG pour une photo classique.
::

::note
Les images sont livrées sans légende. Pour envoyer du texte avec une image, faites-la suivre d'un [Message Texte](/fr/developer-guides/livechat/outgoing-messages/text_message).
::
