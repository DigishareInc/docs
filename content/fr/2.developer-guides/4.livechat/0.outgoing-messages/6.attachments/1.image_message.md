---
title: Message Image
description: Envoyez une image JPEG ou PNG dans une conversation.
icon: i-mdi-image-outline
---

Envoyez une photo ou un visuel. L'API WhatsApp accepte les images **JPEG** et **PNG** (8 bits RVB ou RVBA) jusqu'à **5 Mo**. Les autres types de fournisseur ont des limites différentes : voir [Limites de taille des fichiers](/fr/developer-guides/livechat/outgoing-messages/attachments#limites-de-taille-des-fichiers).

Envoyez-le par lien ou par upload : voir [Pièces jointes](/fr/developer-guides/livechat/outgoing-messages/attachments) pour les différences entre les deux, tous les champs et les règles communes.

## Par lien (API d'événements)

::api-playground
---
method: POST
url: "https://api-app.digishare.ma/v1/event/conversation_message"
headers:
  Authorization: "Bearer VOTRE_TOKEN"
  Content-Type: "application/json"
body:
  event_type: "conversation_message"
  conversation_id: "CONV_123"
  send_to_third: true
  type: "image"
  body:
    link: "https://example.com/images/promo.jpg"
    caption: "Votre texte ici"
responseSample:
  event_id: "2633736349319958528"
  status: "accepted"
  timestamp: "2026-10-02T20:55:33.894921622Z"
---
::

Le lien doit être public et en HTTPS, et `type` doit correspondre au fichier : Digishare ne l'inspecte pas. Le fichier n'est pas visible dans l'inbox Digishare. Voir [Envoi par lien](/fr/developer-guides/livechat/outgoing-messages/attachments#envoi-par-lien).

## Par upload (API Messages)

::api-playground
---
method: POST
url: "https://api.digishare.ma/v1/messages"
headers:
  Authorization: "Bearer VOTRE_TOKEN"
  Content-Type: "application/json"
body:
  send_to_third: true
  conversation_id: "CONV_123"
  file:
    url: "https://example.com/images/promo.jpg"
    file_name: "promo.jpg"
    caption: "Votre texte ici"
responseSample:
  data:
    object: "Message"
    id: "MSG_ID"
    conversation_id: "CONV_123"
    type: "image"
    body:
      id: 48214
      name: "promo"
      file_name: "promo.jpg"
      mime_type: "image/jpeg"
      extension: "jpg"
      size: 184220
      type: "image"
      url: "companies/public/message/48214/promo.jpg"
      path: "companies/public/message/48214/promo.jpg"
      caption: "Votre texte ici"
      content: "Votre texte ici"
    send_to_third: true
    system: false
    status: "sent"
---
::

::warning
**Le WebP est livré comme sticker.** Un fichier `.webp` est envoyé à WhatsApp comme sticker, pas comme image, et les stickers sont limités à 100 Ko (statique) ou 500 Ko (animé). Le `type` du message dans la réponse de l'API est `webp`. Convertissez en JPEG ou PNG pour une photo classique.
::

::note
**Ajoutez une légende** avec `caption` (`body.caption` par lien, `file.caption` par upload) : le texte arrive sous l'image dans le même message. Voir [Texte avec une pièce jointe](/fr/developer-guides/livechat/outgoing-messages/attachments#texte-avec-une-pièce-jointe).
::
