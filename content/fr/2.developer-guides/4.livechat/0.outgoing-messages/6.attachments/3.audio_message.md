Envoyez un fichier sonore. WhatsApp accepte **AAC**, **AMR**, **MP3**, **M4A** et **OGG (Opus)** jusqu'à **16 Mo**. Les autres types de fournisseur ont des limites différentes : voir [Limites de taille des fichiers](/fr/developer-guides/livechat/outgoing-messages/attachments#limites-de-taille-des-fichiers).

Passez l'audio dans l'objet `file`. Voir [Pièces jointes](/fr/developer-guides/livechat/outgoing-messages/attachments) pour tous les champs, l'option base64 et les règles communes.

## Fichier audio

::api-playground
---
method: POST
url: "https://api.digishare.ma/v1/messages"
headers:
  Authorization: "Bearer VOTRE_TOKEN"
  Content-Type: "application/json"
body:
  send_to_third: true
  conversation_id: "CONV_123"
  file:
    url: "https://example.com/audio/bienvenue.mp3"
    file_name: "bienvenue.mp3"
responseSample:
  data:
    object: "Message"
    id: "MSG_ID"
    conversation_id: "CONV_123"
    type: "audio"
    body:
      id: 48216
      name: "bienvenue"
      file_name: "bienvenue.mp3"
      mime_type: "audio/mpeg"
      extension: "mp3"
      size: 523488
      type: "audio"
      url: "companies/public/message/48216/bienvenue.mp3"
      path: "companies/public/message/48216/bienvenue.mp3"
    send_to_third: true
    system: false
    status: "sent"
---
::

## Message vocal

Définissez `voice: true` pour livrer le fichier comme message vocal WhatsApp, avec le bouton de lecture rond et la forme d'onde, plutôt que comme simple pièce jointe audio.

```json
{
  "send_to_third": true,
  "conversation_id": "CONV_123",
  "file": {
    "url": "https://example.com/audio/reponse.ogg",
    "file_name": "reponse.ogg",
    "voice": true,
    "duration": 12
  }
}
```

::warning
**Les messages vocaux doivent être en OGG avec le codec Opus.** Si `voice` vaut `true` mais que le fichier est en MP3, M4A, AAC ou AMR, il est livré comme pièce jointe audio classique et non comme message vocal. Digishare ne convertit pas le fichier à votre place.
::

::note
Les fichiers dont l'extension n'est pas acceptée par WhatsApp comme audio (par exemple `.webm`) ne sont pas garantis de pouvoir être lus. Convertissez-les d'abord en OGG (Opus) ou MP3.
::
