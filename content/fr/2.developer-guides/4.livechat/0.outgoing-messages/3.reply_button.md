---
title: Boutons de Réponse
description: Envoyez des boutons de réponse interactifs pour des réponses rapides.
icon: i-mdi-send
---

Idéal pour les confirmations rapides (Oui/Non). Maximum 3 boutons.

::api-playground
---
method: POST
url: "https://api-app.digishare.ma/v1/event/conversation_message"
headers:
  Authorization: "Bearer VOTRE_TOKEN"
  Content-Type: "application/json"
body:
  event_type: "conversation_message"
  conversation_id: "CONV_123"
  send_to_third: true
  type: "interactive"
  body:
    type: "button"
    header:
      type: "text"
      text: "Confirmation"
    body:
      text: "Confirmez-vous la réception ?"
    action:
      buttons:
        - type: "reply"
          reply:
            id: "btn_yes"
            title: "Oui"
        - type: "reply"
          reply:
            id: "btn_no"
            title: "Non"
responseSample:
  event_id: "2633736349319958528"
  status: "accepted"
  timestamp: "2026-10-02T20:55:33.894921622Z"
---
::

::note
Il s'agit de l'[API d'événements](/fr/developer-guides/livechat/conversation/send-message-conversation) : la requête est mise en file d'attente et reçoit immédiatement un `202`.
::
