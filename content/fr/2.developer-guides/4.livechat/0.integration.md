Ce guide décrit l'intégration technique avec le système Digishare LiveChat. L'intégration est bidirectionnelle :

1.  **Webhooks** : Votre système écoute les événements en temps réel (Nouvelles Conversations, Messages Entrants).
2.  **API** : Votre système envoie des réponses à l'utilisateur via l'API Digishare.

::note
Assurez-vous d'avoir votre **Jeton d'Accès** (Access Token). Voir [Authentification](/fr/developer-guides/authentication) pour plus de détails.
::

## 1. Webhooks

Votre système doit exposer un point de terminaison **POST** pour recevoir les payloads d'événements de Digishare.

### Événements

::accordion
::accordion-item{label="Nouvelle Conversation" icon="i-mdi-plus"}
**Événement** : `live_chat.new_conversation`

Déclenché lorsqu'un utilisateur initie une nouvelle conversation. Utilisez `data.id` (ID de conversation) pour envoyer des réponses.

**Payload :**

```json
{
  "event": "live_chat.new_conversation",
  "data": {
    "id": "YOUR_CONVERSATION_ID",
    "data": {
      "created_at": "2025-12-03T12:28:50.000000Z",
      "third": {
        "id": "YOUR_THIRD_ID",
        "name": "Adil Chbada"
      }
    }
  }
}
```

::

::accordion-item{label="Message Entrant" icon="i-mdi-arrow-bottom-left"}
**Événement** : `live_chat.new_message`

Déclenché lorsqu'un client envoie un message. `type` indique comment lire `body` : une chaîne pour `text`, un objet pour les localisations, boutons et médias. Voir [Messages Entrants](/fr/developer-guides/livechat/incoming-messages/constraints).

**Payload :**

```json
{
  "event": "live_chat.new_message",
  "data": {
    "id": "YOUR_MESSAGE_ID",
    "data": {
      "conversation_id": "YOUR_CONVERSATION_ID",
      "type": "text",
      "body": "/info",
      "sender": {
        "model_type": "third",
        "name": "Adil Chbada"
      }
    }
  }
}
```

::
::

## 2. Envoi de Messages

Digishare propose deux façons d'envoyer. Pour la plupart des intégrations, utilisez l'**API d'événements** : elle met votre message en file d'attente et répond en quelques millisecondes, de sorte que les rafales de messages ne surchargent ni votre intégration ni Digishare. Pour une référence détaillée sur chaque type de message (texte, localisation, interactif, pièces jointes), voir [Messages Sortants](/fr/developer-guides/livechat/outgoing-messages/text_message), dont [Pièces jointes](/fr/developer-guides/livechat/outgoing-messages/attachments) pour les images, vidéos, fichiers audio et documents.

|                      | **API d'événements** (recommandée)                                              | **API Messages**                                                      |
| :------------------- | :------------------------------------------------------------------------------ | :-------------------------------------------------------------------- |
| **Endpoint**         | `POST https://api-app.digishare.ma/v1/event/conversation_message`               | `POST https://api.digishare.ma/v1/messages`                           |
| **Traitement**       | Mise en file d'attente. Renvoie `202` aussitôt ; le message est créé un instant plus tard. | Synchrone. Renvoie le message créé.                          |
| **Conversation**     | `conversation_id`, ou `recipient_id` + `channel` + `api_provider_instance_id`   | `conversation_id` (requis)                                            |
| **Types de message** | Texte, localisation, interactif, pièces jointes **par lien**                    | Texte, localisation, interactif, pièces jointes **par upload** (`file`) |
| **Extras**           | `event_id` pour retrouver le message plus tard                                  | `reply_to` ; le message créé dans la réponse                          |
| **Limites**          | 1 Mo par événement                                                              | 100 Mo par requête                                                    |

### API d'événements

Envoyez un message et recevez un `202 Accepted`. Voir [Envoyer un Message](/fr/developer-guides/livechat/conversation/send-message-conversation) pour tous les champs.

**Point de terminaison** : `POST https://api-app.digishare.ma/v1/event/conversation_message`

::api-playground
---
method: POST
url: "https://api-app.digishare.ma/v1/event/conversation_message"
headers:
  Authorization: "Bearer VOTRE_TOKEN"
  Content-Type: "application/json"
body:
  event_type: "conversation_message"
  conversation_id: "VOTRE_ID_CONVERSATION"
  type: "text"
  send_to_third: true
  body: "Bonjour ! Comment puis-je vous aider ?"
responseSample:
  event_id: "2633736349319958528"
  status: "accepted"
  timestamp: "2026-10-02T20:55:33.894921622Z"
---
::

### API Messages

À utiliser quand vous avez besoin du message créé dans la réponse, de `reply_to`, ou pour envoyer un fichier.

**Point de terminaison** : `POST https://api.digishare.ma/v1/messages`

::steps

### Préparer le Payload

Construisez un corps JSON avec le contenu du message et l'ID de la conversation cible.

### Envoyer la Requête

Envoyez la requête avec votre Jeton Bearer.

### Vérifier

Assurez-vous de recevoir une réponse `200 OK` ou `201 Created`.
::

### Corps de la Requête

| Paramètre         | Type          | Requis     | Description                                                                                                       |
| :---------------- | :------------ | :--------- | :---------------------------------------------------------------------------------------------------------------- |
| `body`            | String/Object | **Oui**\*  | Contenu du message : une chaîne pour `text`, un objet pour `location` et `interactive`.                           |
| `file`            | Object        | **Oui**\*  | Une pièce jointe (image, vidéo, audio ou document). Voir [Pièces jointes](/fr/developer-guides/livechat/outgoing-messages/attachments). |
| `conversation_id` | String        | **Oui**    | ID de la conversation : issu de l'événement webhook, ou de [Créer une conversation](/fr/developer-guides/livechat/conversation/create-conversation).                     |
| `send_to_third`   | Boolean       | **Oui**    | Mettre à `true` pour livrer à la plateforme de l'utilisateur (par ex. WhatsApp).                                  |
| `type`            | String        | Non        | `text` (par défaut), `location` ou `interactive`. Inutile avec `file` : le type est détecté à partir du fichier.  |
| `reply_to`        | String        | Non        | ID d'un message de la même conversation à citer.                                                                  |

\* Envoyez `body` **ou** `file`. `body` est requis sauf si vous envoyez un `file`.

::api-playground
---
method: POST
url: "https://api.digishare.ma/v1/messages"
headers:
  Authorization: "Bearer VOTRE_TOKEN"
  Content-Type: "application/json"
body:
  body: "Bonjour ! Comment puis-je vous aider ?"
  conversation_id: "VOUS_AVEZ_L_ID"
  send_to_third: true
---
::
