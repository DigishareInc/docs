---
title: Message Média
description: Images, vidéos, audio et documents envoyés par le client.
icon: lucide-paperclip
---

Lorsqu'un client envoie une photo, une vidéo, un message vocal ou un fichier, votre webhook reçoit un événement `live_chat.new_message`. Le `type` indique la nature du fichier, et `body` décrit le fichier enregistré.

::note
Les messages clients se reconnaissent à `data.sender.model_type: "third"`. Ne vous fiez pas à `send_to_third` : il vaut `false` sur les messages texte mais `true` sur les messages média.
::

## Types

| `type`  | Ce que le client a envoyé                                     |
| :------ | :------------------------------------------------------------ |
| `image` | Une photo ou une image (JPEG, PNG, WebP).                     |
| `webp`  | Une image WebP. Traitez-la comme `image`.                     |
| `video` | Une vidéo (MP4, WebM).                                        |
| `audio` | Un message vocal ou un fichier audio (OGG, MP3, ...).         |
| `pdf`   | Un document PDF.                                              |
| `other` | Tout autre document (DOCX, XLSX, ZIP, ...).                   |

## Payload

Tous les types de média partagent la même structure de `body`.

```json
{
  "event": "live_chat.new_message",
  "data": {
    "id": "msg_img123abc456",
    "data": {
      "conversation_id": "conv_abc123xyz789",
      "system": false,
      "type": "image",
      "body": {
        "id": 48213,
        "name": "photo",
        "file_name": "photo.jpg",
        "mime_type": "image/jpeg",
        "extension": "jpg",
        "size": 184220,
        "type": "image",
        "url": "companies/public/message/48213/photo.jpg",
        "path": "companies/public/message/48213/photo.jpg",
        "voice": null,
        "is_voice": null,
        "duration": null
      },
      "send_to_third": true,
      "sent_using": "whatsapp",
      "created_at": "2026-10-02T09:14:31.000000Z",
      "sender": {
        "id": "sndr_thd_pqr456stu012",
        "model_type": "third",
        "model_id": "thd_pqr456stu012",
        "name": "Fatima Zahra"
      }
    }
  }
}
```

### Champs du body

| Champ         | Type    | Description                                                                                              |
| :------------ | :------ | :------------------------------------------------------------------------------------------------------- |
| `id`          | Number  | ID interne du fichier enregistré.                                                                        |
| `name`        | String  | Nom interne du fichier enregistré. Ce n'est pas toujours le nom du fichier : utilisez `file_name`.       |
| `file_name`   | String  | Nom du fichier tel qu'enregistré.                                                                        |
| `mime_type`   | String  | Type MIME, par ex. `image/jpeg`, `video/mp4`, `audio/ogg`, `application/pdf`.                            |
| `extension`   | String  | Extension du fichier, sans le point.                                                                     |
| `size`        | Number  | Taille en octets.                                                                                        |
| `type`        | String  | Identique au `type` du message.                                                                          |
| `url`, `path` | String  | Chemin du fichier dans le stockage. Ce n'est **pas** un lien public. |
| `voice`, `is_voice`, `duration` | Mixed | Audio uniquement, et généralement `null` pour les fichiers envoyés par les clients. |

## Autres types que vous pouvez recevoir

Gérez les valeurs de `type` inconnues sans erreur : ignorez-les plutôt que de faire échouer le webhook.

| `type`        | `body`                                                                                              |
| :------------ | :-------------------------------------------------------------------------------------------------- |
| `sticker`     | `null`. L'image du sticker n'est pas incluse dans le payload.                                       |
| `contacts`    | Un tableau de cartes de contact partagées.                                                          |
| `unsupported` | Un objet avec un tableau `errors` : le canal a livré un type de message que Digishare ne peut pas afficher. |
