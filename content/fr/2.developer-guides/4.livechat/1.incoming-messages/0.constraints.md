Lorsqu'un client envoie un message, votre webhook reçoit un événement `live_chat.new_message`. Un message client est celui où `data.sender.model_type` vaut `"third"`.

::note
N'utilisez pas `send_to_third` pour distinguer les messages clients des messages agents. Il vaut `false` sur les messages texte d'un client mais `true` sur ses messages média.
::

## Types de messages

Le champ `type` de l'événement indique comment lire `body`.

| `type`                                    | `body`                                              | Référence                                                                          |
| :---------------------------------------- | :-------------------------------------------------- | :--------------------------------------------------------------------------------- |
| `text`                                    | Chaîne de caractères                                | [Message Texte](/fr/developer-guides/livechat/incoming-messages/text_message)          |
| `location`                                | Objet avec `latitude` et `longitude`                | [Message de Localisation](/fr/developer-guides/livechat/incoming-messages/location-message) |
| `interactive`                             | Objet avec le bouton ou la ligne de liste choisi    | [Réponse Bouton / Liste](/fr/developer-guides/livechat/incoming-messages/reply_button) |
| `image`, `webp`, `video`, `audio`, `pdf`, `other` | Objet décrivant le fichier enregistré       | [Message Média](/fr/developer-guides/livechat/incoming-messages/media_message)         |
| `sticker`, `contacts`, `unsupported`      | `null`, un tableau, ou un objet avec `errors`       | [Message Média](/fr/developer-guides/livechat/incoming-messages/media_message#autres-types-que-vous-pouvez-recevoir) |

De nouveaux types peuvent apparaître avec le temps. Ignorez un `type` que vous ne gérez pas au lieu de faire échouer le webhook.

## Limites

| Type            | Composant          | Limite          |
| :-------------- | :----------------- | :-------------- |
| **Texte**       | `body`             | 4096 Caractères |
| **Interactif**  | `header`           | 60 Caractères   |
| **Interactif**  | Titre `button`     | 20 Caractères   |
| **Interactif**  | Titre ligne `list` | 24 Caractères   |
| **Image**       | fichier            | 5 Mo            |
| **Vidéo**       | fichier            | 16 Mo           |
| **Audio**       | fichier            | 16 Mo           |
| **Document**    | fichier            | 100 Mo          |

Les limites de fichiers indiquées sont celles de WhatsApp Business. Digishare accepte lui-même jusqu'à 100 Mo par fichier, et les autres types de fournisseur diffèrent : voir [Limites de taille des fichiers](/fr/developer-guides/livechat/outgoing-messages/attachments#limites-de-taille-des-fichiers).
